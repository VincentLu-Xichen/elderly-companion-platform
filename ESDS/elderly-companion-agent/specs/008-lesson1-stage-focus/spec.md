# 第 1 课阶段重点与个人练习收束

日期：2026-10-16。状态：已获用户授权并完成实现与验收。基线为 6.2，当前为 6.3。见[实现与验证](implementation.md)。

## 问题与目标

用户体验时发现个人练习持续追问“当时的想法”，并出现模型提供的身体反应和具体念头。现有状态机只在四项记录齐全时进入核对，Prompt 的“不持续盘问”没有对应的程序出口。

本次只调整第 1 课：每阶段让用户看见“练什么、为什么、何时往下走”；个人练习围绕一次经历，允许未获得的信息留下真实缺口。保留九阶段、独立四题、可选补练、本人确认、目标、课后安排和独立复盘。第 2—8 课教学行为及版本保持不变。

## 行为与数据

- 九阶段各有简短的任务、目的和继续条件，随服务端阶段刷新；补练显示相应任务。
- 个人练习的回复和下一问题由服务端选择；模型识别本轮原话，不能用自拟念头或身体反应推动对话。该环节不展示模型回复草稿，其他可流式环节保持原机制。
- 四项分别保存本人原话或独立的缺失说明。`draft_record` 只存带来源的本人原话；缺失说明不成为想法、情绪或能力结论。
- 本人可对当前项操作“暂时想不起”“这一项先不谈”，操作零调用、保留来源 ID。两次回答后当前项仍未获得时，本次记作“暂未整理清楚”并转下一项；次数只是防重复追问边界，不是重要性或能力指标。
- 四项均已表达或暂留后进入核对；本人确认的是已表达内容及缺失说明。即使四项均暂留也可继续，个人应用标明未观察，不能宣称已完成完整四要素整理。
- 核对页可重新补充暂留项；重开后撤回旧确认、目标和派生成果，保留既有检验快照。新原话覆盖相应暂留状态，不能自动推断缺失内容。
- 完成产物、授权摘要、课后复盘保留缺失状态。后课仅沿用实际存在的同义原话，不将缺失状态当作本人经历。复盘可提出有来源的教学建议，不以缺失推断人格、能力或病情。
- 6.2 及更早版本只读；不迁移、不重启已有体验进程或清除用户数据。无数据库表变更，使用现有加密状态、Trace、幂等、串行与授权机制。
- 原有 `invalid_evidence` 原因未在本次得到全面修复；来源与精确摘录守卫继续生效，无隐藏修复调用。

## 验收

1. 短回答、跨项回答和连续未获得当前项时，提问次数有界，实际获得的信息保留。
2. 明确暂留操作不调用模型、不造原话、不伪造答对或掌握；非法阶段/课次操作拒绝。
3. 缺项确认后能继续独立检验及完成，成果与复盘保留缺失范围；修改能重新获得暂留项。
4. 页面每阶段有目标提示，个人练习有明确暂留按钮，刷新后状态一致；旧版只读。
5. 来源校验、权限、加密、幂等、失败原子性及其余七课回归通过。真实模型专项结果与离线回归分别报告。
