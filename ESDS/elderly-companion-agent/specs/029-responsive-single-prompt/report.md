## 旧版做什么，本次为什么这样改

| 旧行为/约定 | 本次调整 | 理由与限度 |
| --- | --- | --- |
| “每轮只问一个具体问题”“先整理所有字段，再问下一缺项”容易把对话收成问答链 | 明确至多一个问题，也可以不问；先判断本轮是在回答练习、纠正、问概念、倾诉还是暂停 | 给当下诉求明确优先级；不是只加温柔形容词。尚不能由指令证明模型一定会遵循 |
| 听见哭泣后仍直接问相信程度 | 明显难以承受或想被听见时，先回应具体表达，本轮放下评分、填表、说理和核对邀请；愿意继续时再提供本课帮助 | 保留课程目标和原案例，不要求用户先好转或接受积极解释 |
| 模型把当前感受/自我评价直接摘入原事件字段 | 倾诉通常不填observations，原话保留在对话；不自动用此刻感受覆盖原事件当时记录，明确纠正/愿意整理时才提取 | 保护时间、案例和评分对象。原有未答计数和边界动作仍有局限，没有偷偷增加新状态 |
| Schema允许摘录列表，Prompt未明确每字段唯一，程序却拒绝重复字段 | 统一条数说明，每field至多一条连续忠实摘录；不能拼接伪造、把意愿当已发生行为 | 对齐现有业务约束；程序仍拒绝不合约JSON，不静默丢字段或放宽来源校验 |

这次是**主Prompt修订包**，同时调整回应优先级、提问时机与摘录约定；未来对照只能说明整包的表现，不能分离出每句话的独立贡献。没有新增Agent、任务Prompt路由、额外反思调用、示例库或模型参数实验。第一课必要的模型回顾、练习、目标、自愿课后安排和正常评分引导保留。
