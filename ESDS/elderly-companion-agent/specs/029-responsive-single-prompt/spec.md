## 验收和限制

- 强烈难过的首轮不机械拉回打分或记录核对，不以“您/不勉强”作为唯一改善证据；允许有分寸的邀请，也允许纯回应。
- 当用户明确想被听见时，不要求补评分/原因；愿意恢复整理时，根据已知原话提供第一课帮助，不重讲全套记录。
- `observations`不要求每条对话填字段。每个field至多一条连续忠实摘录；当前案例/时间不明确或仅是暂聊时可为空，原话仍在对话。明确纠正继续按证据处理。
- 程序原来的重复字段/无效来源拒绝仍有效；不能只删除guard或静默吞掉第二条来取得通过。Prompt只能降低不合约输出的机会，不能证明程序级绝不再失败。
- 当前程序仍会对未收集字段计有限未答、以既有interaction处理拒绝/暂停；本片没有新增“倾诉”状态或自动长期偏好。若实测暴露这些限制，保留失败，另切片处理，不偷偷扩修。
- 必须保留正常引导评分、评分困惑与拒绝的原案例/证据；本轮离线回归不等于验证这些情况下LLM始终响应正确。
