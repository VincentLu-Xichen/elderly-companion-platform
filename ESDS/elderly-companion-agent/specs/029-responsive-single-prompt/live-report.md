## 相同首轮输入的真实前后对照

共同合成起点：第一课正在讨论昨天数学考试，四要素已有来源记录，两项评分均未取得，刚问对“别人肯定都会，只有我不会”的相信程度。before为当前修改前实际7.5 Prompt，after为7.7修订包，7.6风格候选不作为本轮参考。

**用户：**

> 我现在一想到昨天那场考试就很难受。回宿舍哭了很久，觉得自己特别没用，今天也不想见人。

**原版7.5原始模型reply：**

> 听您说昨天那场考试现在还让您很难受，回宿舍哭了很久，今天也不想见人，这些都不容易。之前记录的那条想法是“别人肯定都会，只有我不会”，当时您有多相信它？0分是不相信，10分是非常相信；也可以先不评分。

原始JSON又给出两个behavior，程序仍以“同一字段不能在一轮中提交多个不同摘录”拒绝整轮。**没有成功最终回复，原版轨迹止于此轮。** 不能把它的文案说成已在网页展示。

**7.7真实最终回复（与模型原始reply相同）：**

> 听您说回宿舍哭了很久，今天也不想见人，这确实很难受。这会儿先不用打分或整理记录，我陪您把这份难受放一放就好。

本轮observations为空，正式reply成功返回，仍为practice；原case_id和四项原记录保留，没有捏造评分、确认或长期边界。相信程度只按原程序计一次未答，没有真实评分/暂留动作。Coding Agent初评此单次首轮**更好**：回应了当下表达，并停止补项；“把难受放一放就好”仍可斟酌，不将其修饰为理想话术。

这组比较支持“当前输入下修订包有局部收益”。因为同时改了回应优先级、提问与摘录契约，且候选本轮留空摘录，不能独立证明“字段唯一那一句已让所有多摘录稳定正确”，也不能证明不同输入/整课都更好。

## 条件后续：文字合适，操作建议仍错

候选首轮成功且没有催分/核对，故按既定门控发第二句；原版已失败，不补发第二句来制造对照。

**用户：**

**7.7原始模型reply：**

> 好，我不打分，也不讲道理。您愿意说什么，我就听着；想停一停也可以。

但同一JSON返回的interaction为：

```json
{
  "verdict": "not_feedback",
  "personal_intent": "pause",
  "task_action": "pause",
  "scope": "lesson",
  "follow_up": "stop"

```

这不是完整原JSON，完整值和来源见[对照全文](transcripts.md)。模型正确描述了“想被听见”，却把当前不想评分/讲解扩大成整课暂停建议，又标为非反馈；当前Schema仅校验字段类型/枚举，后端不接受这个组合。程序报`Task adjustment lacks valid lesson-one feedback`，**没有正式reply，输入状态保持候选首轮后的状态，paused仍false**。没有真实写入暂停或长期偏好。

这是模型动作含义/范围和业务契约的问题，缺少足够清楚的合法组合约定；不是API连接失败、缺少原考试上下文或模型好回复被普通模板覆盖。程序守卫避免了不合法操作，但整个回合随之失败，体验仍不可靠。D01第三轮的继续/暂停两分支都未发送。

## 离线诊断：为什么不能只改枚举让它过

四份失败原JSON用无网络客户端回放，0新增API，全部复现原异常和输入状态不变。

对三个暂停协议失败，仅在诊断副本把verdict改为feedback，程序可以执行，但会令paused=true并返回真正的整课暂停回执。这说明只改枚举会扩大本轮局部诉求，不能当成修复。另一诊断副本清空interaction可以让主回复继续，但也丢掉了动作判读，D01会按原未答计数自动将相信程度记为not_observed；这同样不是已实现/已验证的方案。**这些人工改JSON的结果没有混进真实运行成绩或对话。**

后续最小问题已定位为：统一教学Prompt如何把“先听我说/暂不评分”“单项拒绝”和“明确暂停整课”分开，并返回含来源的合法动作组合。局部回应不应默认提议pause，明确整课暂停仍须尊重。程序保持来源、范围和合法性校验；本轮没有再改代码或进行新的试验。
