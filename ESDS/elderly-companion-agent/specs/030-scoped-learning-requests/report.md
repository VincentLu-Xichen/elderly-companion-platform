## 旧行为与这次修改

1. 029把“先听我说、先别评分”写成not_feedback＋pause，程序拒绝。只改feedback会真的停整课；删interaction仍会把倾诉计为未回答评分。030把普通学习请求独立为四字段learning_request，讲法Reflexion、个人经历边界、课末复盘继续各管原职责。
2. mode=listen时回应当下需要，不消耗作答次数，不改原案例；评分暂留是独立字段，所以可以边倾听边明确暂不评分。mode=continue配合评分暂留可解释原例；引用旧句子讲概念不再提交为新记录。mode=pause_lesson才执行暂停回执，不代替本人确认或完成。
3. 程序继续验证来源、合法阶段与范围。只讲痛苦却被模型加上评分拒绝时，缺少任何评分/局部拒答候选依据的提议不采用、保留审计；规则只拦无依据的动作，不据匹配推断拒绝或心理。新旧重复pause含义一致时允许；pause附带的评分修改不执行，不让多余字段阻断独立有效的停课。
4. 普通教学仍一个Agent、每课统一主Prompt，现有候选触发辅助和课末Reflexion保留；不新增模型调用层。局部请求按原独立加密路径保存为observed，不加载成active风格偏好或跨课教学假设。主Prompt、Schema与控制器是一个协议修订包，不独立归因某一条Prompt。

第二课6.2完整Prompt、原辅助基础Prompt、检验Schema、模型参数、Daily Chat、前端、数据库结构与API配置未改。第一课新增请求类型仅本课learn/practice/review使用；不恢复后六课。
