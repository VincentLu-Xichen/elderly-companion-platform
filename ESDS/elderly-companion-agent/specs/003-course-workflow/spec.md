# 第 1—3 课共用工作流实现规格

> 此为前三课实现阶段的历史规格。2026-10-16 起，当前八课版本以[八课规格](../004-eight-lessons/spec.md)为准，旧记录仍保留只读。

状态：2026-10-15，按用户“完善工作流、完成 1—3 课并从代码讲解”的授权实施。依据[架构设计 v0.3](../002-lesson-3-design/spec.md)，本规格明确本次要交付的运行行为。

## 范围与版本

- 第 1 课四要素、第 2 课三栏、第 3 课思维习惯辨认，均使用六阶段和本人确认成果。
- 共享运行时版本 `guided_cbt_v2`，Agent 版本 `course-guided-v2`；第 1、2 课版本 `4.0-feedback-flow`，第 3 课 `1.0-feedback-flow`。旧版本保留只读，不覆盖旧 Prompt 或状态，也不自动迁移旧成果。
- Daily Chat、历史角色语境和数据库表结构不变。新增状态、反馈、反思和调用记录继续使用现有加密列。

## 课程与课间数据

| 课 | 必要个人记录 | 特有操作 | 可承接来源 |
| --- | --- | --- | --- |
| 1 | 事情、想法、心情、做法 | 本人核对四要素 | 新例子 |
| 2 | 事情、想法、心情 | 本人核对三栏 | 同一参与者当前版本已完成第 1 课 |
| 3 | 事情、想法、心情、本人对推断依据的说明 | 对一个可选思维模式选择符合、不符合、不确定或无明显模式，再确认整份记录 | 优先第 2 课，缺失时第 1 课；每次一份 |

接受摘要仅允许引用；在个人练习时另有明确的“沿用这件事”操作，保留来源成果/字段和本课采用依据，不伪造本课摘录。新例子仍可独立完成；未确认的引用草稿在来源失效时撤回。本人确认后的新成果是独立的本人报告快照，保留出处，不反向改写旧成果。

第 3 课不强制接受分类，没有候选时也可以保留不确定或无明显模式。模型解释不进入本人原话。活动中的已确认记录可以显式重新编辑，课后选择随之重选；完成后只读。

## 常规轮次与可选反思

1. 先保存用户消息、pending 审计并取得处理租约。
2. 常规模型一次返回自然回复草稿、精确摘录、任务反馈信号、可选领域候选、阶段建议。
3. 程序校验原话、来源、字段、阶段；形成候选状态并执行冻结的触发策略。
4. 未触发时采用经校验的常规回复；触发时额外调用 Reflector，校验短结论和白名单策略，再调用 Actor 生成最终回复。
5. 保存最终状态、反思应用关系、各次模型元数据与回复，释放租约。中间结果不作为已提交学习进度。

触发策略支持 `none`、`per_turn`、`per_task_step`、`event_driven`。默认部署使用 `none` 作为对照，隔离体验默认 `event_driven` 并明确它是试用规则；每个新会话冻结策略和规则版本，后续环境变化不能静默更改已有会话。

task step 由程序从当前阶段与首个待补字段计算；阶段是 phase，单轮是 turn，三者分别记录。按子任务触发只比较普通教学轮次的前后目标变化；确定性本人操作记录为跳过模型评估，不伪造反思调用。

事件规则优先考虑有来源的不理解/纠正、同一目标持续无进展以及有可比依据的字段冲突。阈值是初始可审查规则，不是经过实验的最优参数；不按时间、长度或情绪词给精神状态打分。所有策略均保留相同的常规记录能力。

当前参考拓扑未触发通常一次调用，触发三次；课后复盘仍是独立一次。每个阶段有 Prompt 指纹、模型、usage、耗时和错误元数据，保存在加密 trace 中；聚合 tokens 如有缺失则不虚构总数。普通调用设定明确的输出上限和超时，不能暗中增加 JSON 修复调用。

反思短结论有消息依据、目标和单一策略；不能确认、授权、改写本人事实或决定完成。下一次有新信息时重新检查策略适用性；课间不传整段反思。

## 失败、重试与审计

- 任一模型失败、结构错误、伪造来源、租约过期均不提交候选状态或助手回复，保留用户消息和失败审计。
- 同幂等键重试必须使用原输入/操作；本次实现重新执行模型阶段，保留各次失败的调用成本与轨迹，不承诺缓存中间候选。
- 成功请求重放不重复消息或模型调用，过期修订号不能确认旧记录。
- 课后复盘失败不撤销完成，保留独立审计、重试和不自动跨课应用的行为。

## 体验与代码讲解

- 课程目录开放第 1—3 课，4—8 保持占位。
- 沿用对话与记录并排展示，增加来源、采用已有案例、分类核对和显式修订；手机端操作可用。
- 仅隔离体验提供流程观察区，展示本轮目标、触发理由、调用数量和简短反思；正常学习页面不堆实现字段。
- 提供无真实密钥的三课跟踪脚本，输出逐轮状态、触发和调用轨迹；不同策略可重复运行。离线规则只验证流程，不证明真实模型或教学收益。
- 编写基于实际代码的阅读路线、关键数据示例、前后对照与验证记录。

## 验收

三课完整 API/持久化流程、不同课 Prompt 和成果；三课均可无前课开始；接受/拒绝/删除/版本不符的引用；第 3 课拒绝或不确定仍可完成；确认后显式修订；四种策略的触发边界和常规状态一致；来源伪造与超权限反思拒绝；Reflector/Actor 失败不推进及同键重试；加密、并发租约、幂等、旧版只读和导出回归；电脑与手机页面；Python/JavaScript 语法。

本轮不运行真实付费模型实验，不据测试数量断言触发策略最优。
