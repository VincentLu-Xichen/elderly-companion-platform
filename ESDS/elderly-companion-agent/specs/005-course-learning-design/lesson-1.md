# 第 1 课认知行为三角教学与检验稿

日期：2026-10-16。状态：依据已同意的[八课教学方向](spec.md)细化的材料，已接入可体验首版；题干、判据及待定选项仍可根据体验调整，未视为最终教学定稿。具体已实现与待办见[实现说明](implementation-lesson-1.md)。本文示例人物、回答和结果均为虚构。

第一课帮助学习者初步区分事情、想法、情绪和行为，并在帮助下整理一次经历。课末用不同案例检查概念辨认，随后汇总有依据的学习结果，形成供第二课核对的指导建议。

## 本课目标与证据

| 本课目标 | 可以观察的证据 | 不能据此推断 |
| --- | --- | --- |
| 初步辨认四要素 | 新案例中各题的回答、理由和帮助记录 | 已经永久掌握或能应对所有生活情境 |
| 在帮助下整理一次经历 | 过程中的原话、追问和本人核对 | 填完记录就能独立完成 |
| 初步注意各部分的联系 | 本人对案例的发现，允许暂时没发现 | 情绪完全由想法造成或必须变得积极 |
| 形成自己的练习方向 | 本人选择并确认的目标或暂未决定 | 同意目标就已经改变，选择跳过就没有能力 |

个人经历的内容、情绪和偏好由本人表达与核对；知识检验评价其对给定案例的辨认，两类依据分别保存。用户使用虚构案例练习时，个人经历应用记为未观察。

## 环节一 说明目标与简单签到

**目的**：让本人知道本课练什么，按可接受的节奏开始。

引导示例：

> 今天我们一起练习把一件小事里的事情、想法、心情和做法分开看。我会先举个例子，再陪您试一次，最后换个例子看看讲清楚了没有。

随后另问一项：

> 最近这一周过得怎么样？愿意的话，可以简单说说。

若保留原版近况评分，可说明一到十分的含义并接受跳过；不能从一个分数推断诊断、学习能力或课程成效。是否评分列入本稿待讨论项，不在程序中改变当前行为。

## 环节二 短示范

**目的**：提供四要素的生活化参照，降低直接整理个人经历的起步负担。

示范按短段呈现，避免一次讲完长故事并要求记忆：

> 小林昨晚给朋友打了电话，朋友当时没接。小林想到“他是不是不愿意理我”，感到失落，后来没有再打。

> “电话当时没接”是发生的事；“他是不是不愿意理我”是小林的想法；失落是心情；没有再打是做法。

再换一个小故事进行引导，避免把已经讲明的示范答案重复当作问题：

> 小周买菜时，发现常去的摊位今天没开。他心里冒出一句：“今天买不到想要的菜了。”他有些失望，随后去旁边的摊位看看。

只问一个尚未说明分类的问题：

> 这里“今天买不到想要的菜了”属于事情、想法、心情、做法中的哪一部分？

先等本人回答，再解释和示范，不在问题后立即自己给出分类。这一回答属于引导练习，不记成课末独立检验。本人不确定时，帮助区分“目前知道什么”和“脑中怎样理解”，不要求使用术语，也不要求改成积极解释。回答后衔接个人练习，不在本环节逐项重考整个示范。修订说明见 [007](../007-lesson1-guided-example/spec.md)。

## 环节三 引导个人练习

**目的**：把概念用于本人愿意讨论的具体经历，并观察需要怎样的帮助。

先邀请选材：

> 最近有没有一件愿意聊的小事？不想谈自己的事，也可以继续用虚构例子练。

以下是对话方向，不是每次都机械重复的问卷。本人已在一句话中清楚表达的内容，应先整理并核对，不重复索取。

| 需要了解什么 | 单轮提问示例 | 引导边界 |
| --- | --- | --- |
| 事情 | “那次具体发生了什么？” | 区分本人报告与对他人的推断；身体不适可作为本人经历保留，不擅自解释医学原因 |
| 想法 | “当时您脑中最先冒出来的是哪句话？” | 保留否定、不确定和转述，不替本人补充，也不把别人的话记成本人想法 |
| 心情 | “那会儿您是什么心情？” | 接受本人表达；需要词汇支持时提供少量选择并让本人决定，不能代选 |
| 做法 | “后来您做了什么，或者没有做什么？” | 区分实际行动、愿望和未来计划，不从“想联系”推定已经联系 |

6.3 按 [008](../008-lesson1-stage-focus/spec.md)新增收束：每项初问后最多一次澄清，仍未获得则如实暂留；本人也可选择“暂时想不起”或“这一项先不谈”。暂留说明与原话分别保存，核对后可以继续新案例测试，不把个人经历填齐作为掌握的证据。每阶段持续显示任务、目的与继续条件。

如果本人说“她肯定不想理我”，可问：

> 这是您当时想到的。那次您具体看到或听到了什么？

这是帮助区分记录的引导，不在第一课要求本人同意思维模式分类或改变观点。

原版两个自我评分的可选提问稿：

- 相信程度：“当时您有多相信这句话？愿意的话，用零到十分表示，也可以先不评分。”
- 情绪强度：“当时这份感受有多强？愿意的话，用零到十分表示，也可以先不评分。”

若采用，应分轮询问，分别记录含义与大致时间，避免与近况心境混在一起。本稿建议作为可选自我观察；是否采用及何时询问，仍待与用户讨论。

## 环节四 本人核对与共同回顾

**目的**：保证记录忠实，并邀请本人注意各部分的联系。

虚构个人练习回顾示例：

> 我听到的是：昨天女儿没有回电话，您想到“她是不是不在乎我”，心里有些失落，后来没有再打。这样整理准确吗？

本人纠正时先修改并重新核对，不让既有总结压过新说明。核对准确后另问：

> 把这几部分放在一起看，您有没有留意到什么？暂时没有发现也可以。

引导可以说明想法、感受和做法可能相互影响，同时承认现实处境也有作用。本人仍然难过、不想改变做法或没有新发现，不据此判断学得不好。

## 环节五 新案例四题检验

**目的**：检查在减少提示的情况下，对四要素的初步辨认。此处不用刚才反复讲解过的电话案例。

建议过渡语：

> 接下来换个例子，看看刚才有没有讲清楚。您可以按自己的理解回答，不用背词；想再看一遍或需要帮助，都可以告诉我。

### 检验案例 A

> 在社区活动室，一位邻居走过来，对老陈说：“早上好。”老陈心里冒出一句：“他会不会觉得我没礼貌？”他有些紧张，低下头，没有回应。

故事在检验期间保持可查看或可重读，避免把记忆负担混入概念辨认。学习者端暂不展示下表答案。

| 题目 | 参考含义 | 可以接受的表达 | 需澄清或不符合的例子 |
| --- | --- | --- | --- |
| Q1 “这个例子里，老陈遇到了一件什么事？” | 邻居走来并向他问好 | “邻居跟他打招呼”“有人对他说早上好” | “邻居觉得他没礼貌”把推测写成已发生的信息 |
| Q2 “老陈当时脑中冒出了什么想法？” | 担心邻居会认为自己没礼貌 | “他怕别人觉得自己不礼貌”“对方会不会觉得他没礼貌” | 只答“紧张”未指出想法；只答“担心”时需要澄清担心的内容 |
| Q3 “故事里明确说到，老陈是什么心情？” | 紧张 | “有点紧张”；“不安”在含义与上下文一致时可接受 | 只复述“他会觉得我没礼貌”仍是想法；身体反应或其他未写明感受需区分 |
| Q4 “老陈随后实际做了什么，或者没有做什么？” | 低下头，没有回应 | “低头了”“没回话”；明确指出其中一项实际做法即可 | “想和人说话”没有说明实际行动；“邻居走过来”主体不同 |

四题分别收集回答，不要求本人一次完成整张表。首次作答阶段采用中性承接，不透露前题正误，也不提前展示四要素答案。本人求助时仍可解释，需保留帮助内容及其影响范围。

判断以含义为依据，接受合理近义表达、口语和“不太确定，但我觉得……”这类明确回答。正确指出目标并额外正确区分其他部分，不因多说内容判错；若把多种内容混在一起而无法确认其分类，先做中性澄清。题干含糊或转写不清时不直接归因为用户错误。

四题主要观察辨认，不足以单独证明已经理解全部关系。反馈后可选问“您是怎样判断这句属于想法的？”，将其作为补充解释依据，不临时扩成第五道必答题。

### 帮助与作答的记录

| 情况 | 记录方式 | 对结果的解释 |
| --- | --- | --- |
| 重读原文、调整字号、换文字或语音呈现且内容不变 | 记录呈现调整 | 不因这种支持降低独立概念辨认评价 |
| 澄清题目在问谁或要求找哪句话，未给概念线索 | 保留原题、澄清内容和回答 | 标明题意澄清；也检查题目或转写问题 |
| 解释“想法与心情怎么区分”等概念后再答 | 保留首次回答、提示和随后回答 | 记获得概念提示后的表现，不能冒充首次独立回答 |
| 直接指出本题答案或先展示答案图 | 记录答案已示范及受影响的题目 | 后续复述只支持示范后完成；独立检验需要新题 |
| 一题提示也透露了同组其他题的信息 | 记录影响范围 | 受影响的后续题一并标记，不能仍称整组独立作答 |
| 不愿作答、暂停、没有听清或无法确定 | 分别保留本人选择和原因 | 允许未观察或需澄清，不自动填成错误 |

以上是教学记录含义，不是已冻结的 API 枚举或计分模型。

## 环节六 反馈与必要补练

**目的**：让检验成为学习反馈，保留之后出现的进展。

四题首次作答结束后，先指出本人已经分清的内容，再解释需要澄清处。示例：

> 您已经找到了邻居问好这件事，也找到了老陈低头、没有回应的做法。我们再看“他会觉得我没礼貌”和“紧张”：前一句是脑中的判断，后一个词说的是心情。

这是反馈与教学，不将紧接着复述出的答案另算为一次独立通过。本人愿意继续时，采用新材料补练相关部分；也可暂时结束，在第二课继续。

### 补练案例 B

> 老李到图书馆借书，门口贴着“今日临时闭馆”。他想到：“我今天的安排全乱了。”他有些失望，随后转身回家。

若首次混淆想法和心情，分轮问“老李脑中出现了哪句话？”及“他的心情是什么？”。参考含义分别为“今天的安排全乱了”与“失望”。保留补练任务、题目、帮助和回答，不覆盖 A 的首次表现。

暂不设置强制补练次数、统一过关分数或答对后才能退出的规则。本人是否继续由其决定；是否完成课程流程与哪些能力尚未观察到分别表达。

## 环节七 学习目标与课后安排

**目的**：将练习与本人愿意关注的生活方向连接，并为第二课提供回顾内容。

目标提问示例：

> 您希望接下来的课程，先帮助您在哪件生活小事上更容易应对一点？

邀请本人提出方向，必要时协助具体化，并请其确认。不要替本人设为“以后不再难过”或将改变感受设为必须达成。建议先聚焦一项，原版一至五条的数量要求列为待讨论项；暂未决定也如实记录。

课后邀请示例：

> 下次碰到一件小事时，您愿意试着留意一下事情、想法、心情和做法吗？可以简单记下，也可以只在心里想一想。

保留愿意、想简化、不安排或尚未决定。下一课询问是否尝试、有什么发现或困难；没有做不要求补齐后才继续。课后新发生的记录是新的本人报告，不从本课示例推定。

## 检验后的学习结果示例

以下仅示范表达含义，不是实际模型输出、真实参与者成绩或最终 Schema。

| 内容 | 虚构结果 |
| --- | --- |
| 本课任务 | A 案例四要素辨认；个人经历四要素整理 |
| 首次作答 | Q1、Q2、Q4 含义符合，Q3 回答为“他怕别人觉得自己没礼貌”，与题目所问心情不符 |
| 帮助与反馈 | 首次四题均无概念提示；统一反馈后重新解释想法与心情 |
| 补练 | B 中两项在未增加概念提示的情况下答为“今天的安排全乱了”和“失望”；属于反馈后的新材料补练 |
| 个人练习 | 在引导下整理本人案例，并由本人核对；独立整理另一段个人经历尚未观察 |
| 目标与选择 | 本人希望先看清一次等待回复时的反应；愿意在生活中留意一次 |
| 证据范围 | 观察到一次引导整理、一次四题检验及相关补练；实际生活使用尚无反馈 |

若需要数量摘要，可以说明本次首次三项符合、另一项需帮助，但不换算为统一能力百分比，不据此宣称训练造成提升。

## 检验后的 Reflexion 示例

**表现依据**：上述虚构 Q3 将想法答作心情；个人练习能用自己的话表达“失落”；概念反馈后在 B 中区分了想法与心情。

**解释假设**：本次可能尚未熟悉“想法”和“心情”术语与日常表达的对应。还需考虑任务表述及不同题目之间的差异，不能仅凭纠正后的回答判定某种讲法必然有效。

**后续调整**：第二课在原有三题复习中关注这一差别，使用“我想到什么”和“我感到什么”的生活化对照；尽量减少提示后再观察。

**核对办法**：观察第二课新材料中是否仍混淆，以及是否需要概念提示。若已能独立区分，就减少这项补练；若表现不同，更新原假设并检查情境和题目，避免持续重复旧判断。

**个体化理解的范围**：本例支持局部的学习支持假设。A、B 都是虚构故事，用户提取“对方觉得我没礼貌”等答案，只支持案例辨认，不能据此认定本人怕被拒绝、缺乏自信或有人际思维习惯。关于本人经历的线索另需本人原话、情境与核对，并保持可修正。

反思在本课检验后汇总，可以结合旧的适用反思；新增逐轮或事件反思的价值仍留待实验。学习结果保存可核对表现，Reflexion 保存解释假设、指导调整和核对办法，两者都可以结构化。反思失败不撤销本人确认记录和已保存的学习结果。

## 本稿需要继续讨论的选择

| 选择 | 当前建议 | 取舍 |
| --- | --- | --- |
| 先示范还是先个人经历 | 先短示范，再进入本人愿意讨论的例子 | 给初学者参照；是否削弱参与感要在体验中观察 |
