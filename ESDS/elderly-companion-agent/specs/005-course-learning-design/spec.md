# 八课教学练习与检验设计

日期：2026-10-16。状态：用户已同意教学设计方向，第 1 课已实现可前端体验的首版，见[实现对照与体验步骤](implementation-lesson-1.md)。第 2—8 课的新检验仍待实现，继续使用 [004 八课工作流](../004-eight-lessons/spec.md)。本文其余通用内容是目标设计，不能整体当作已实现。

课程通过示范、引导练习和学习检验，帮助学习者逐渐使用认知与行为技能。检验后汇总带依据的学习结果，Reflexion 根据这些结果和整课过程，形成可修正的个体化理解与后续指导建议。

本规格确定教学环节和产物的含义。具体题库、字段命名、API、存储方式和模型调用拓扑在后续设计中确定，不将本文直接当作现有接口契约。

## 共同教学流程

回顾前次尝试 → 说明本课目标与示范 → 引导个人练习 → 减少提示进行检验 → 反馈与必要补练 → 课后安排 → 汇总学习结果与 Reflexion。

1. 初次接触者先获得简短、生活化的参照，再选择愿意讨论的小事；可以使用虚构案例或暂不提供个人经历。
2. 引导帮助本人表达和区分内容，不预设其应有的想法、心情或选择。个人记录由本人核对，系统不将自己的解释改写为本人原话。
3. 引导练习与独立检验使用不同案例；任务应考查本课目标，并保持大致可比的难度。
4. 过程保留任务、回答、提示与反馈的依据。正式学习结果在检验后汇总，不能等到课末仅凭印象追溯。
5. 首次回答、获得提示后的回答、反馈后补练分别记录。第 1 课四题逐题询问，首次作答阶段不主动透露正误，完成后统一反馈；本人主动求助时可以提供提示并标注帮助程度。
6. 第 2—8 课按各自目标采用迁移任务、依据检查、计划修订、复述或情境演练，不统一套用四题或单一总分。
7. 支持答错后解释与补练，保留不知道、拒绝、暂停和未完成的状态，不以接受模型解释或情绪变好作为通过条件，也不因没有课外实践而阻止继续学习。
8. 每课末邀请一项可选的生活尝试，下次由本人报告是否尝试、发现和困难。计划、已执行和本人认为有帮助分别记录。

检验后设置一次主要 Reflexion 汇总节点。它可读取本课引导、练习、首次检验、帮助与补练、本人反馈，以及仍适用的旧反思。是否增加逐轮、子任务或事件触发反思仍是后续实验变量，当前不修改运行中的四种策略及默认值。

## 第 1 课 认知行为三角

[逐环节教学与四题检验稿](lesson-1.md)已形成可体验首版：先示范、本人练习与核对、四题结束后统一反馈、可选新案例两题补练、一项目标及课后安排。题目与判据仍待体验修订；相信程度与情绪强度尚未加入。具体实现边界见[对照说明](implementation-lesson-1.md)。

**目标**：初步区分事情、想法、情绪和行为，认识它们可能相互影响，并在帮助下整理一次个人经历。

**教学与个人练习**：说明本课目标并简单签到；用“朋友没回电话”的短例子解释四要素，再由本人选择愿意讨论的小事，逐步询问发生了什么、当时想到什么、有什么感受、实际做了什么。整理后请本人核对，讨论各部分的联系。相信程度与情绪强度属于自我观察；是否保留及必填性在教学细化中明确，不能当作知识得分。

**检验**：换一个未讲解的日常案例，逐题辨认事情、想法、情绪和行为。判断依据按含义设置，接受合理近义表达；记录首次回答、提示与修正，不将完成四题直接表述为已经掌握。

**课后衔接**：保留学习目标建立与本人确认，邀请在生活中留意一次四要素。学习结果区分各概念的表现；第 2 课优先回顾需要支持的区别，并用新任务复核。

## 第 2 课 看见情境想法和心情

**目标**：从概念辨认进到观察自己的经历，理解同一件事下不同解释可能联系到不同心情。

**教学与个人练习**：询问上次尝试；没做或记不清也可继续。保留原版三道认知、情绪、行为分类复习。雨天取消公园之约时，先听本人可能的心情和想法，再对照另一种解释与心情，请其说说发现。邀请本人尽量自行整理一段三栏经历，随后只澄清必要信息。

**检验**：使用“社区活动取消”等新情境，区分事情、解释和情绪，并讨论给定的不同解释可能联系到什么感受。观察个人练习中能否自行组织记录、何处需要提示。情绪体验允许差异，不将回答积极作为正确标准。

**课后衔接**：汇总概念理解、个人应用及帮助程度；邀请一次三栏观察。第 3 课可以在本人选择的记录上继续检查已知信息与推断。

## 第 3 课 看见想法中的习惯

**目标**：觉察解释过程，区分已有信息与推断，并能对思维模式的候选解释作出有依据的核对。

**教学与个人练习**：从一条本人想法入手，询问知道什么、还不知道什么、判断依据是什么。适合时提出一个候选模式并说明依据，保留接受、拒绝、不确定和无明显模式的选择。

**检验**：换新案例，请本人指出一项推断及还需获得的信息；若信息充分，也应能说明为何不是无依据猜测。评价依据检查的表现，不以同意分类作为正确答案。

**课后衔接**：学习结果保存辨认表现、本人核对与不确定项；个人思维线索按情境保存为待核对假设。为第 6 课提供一个可继续检查的具体想法，不据此诊断、固定标签或自动指定治疗路径。

## 第 4 课 相反行为

**目标**：识别情绪推动的冲动和实际行动，结合现实情境与本人目标，考虑有边界的替代回应。

**教学与个人练习**：回顾一段愿意讨论的经历，询问原做法的短期作用与后续影响，再考虑等待、简短沟通、设定边界或其他本人愿意选择的回应。保留暂不行动。

**检验**：对比日常尴尬与存在现实危险或越界的情境，请本人说明何时适合改变做法、何时需要保护边界，并提出理由。评价是否联系情境作判断，不要求机械地做与情绪相反的事。

**课后衔接**：保存行动判断、本人考虑的替代与条件；第 5 课可以将愿意考虑的方向具体化。目录名称沿用原项目；材料中说明该技能与 DBT 的联系。

## 第 5 课 行为激活与行为暴露

**目标**：根据本人选择，将有意义的活动或安全日常回避的探索整理为可调整的小步计划。

**教学与个人练习**：先解释两路目的，由本人选路。激活讨论活动对本人的意义和可考虑的第一步；暴露讨论没有现实危险的日常情境、担心的预测、本人感受的难度台阶和可观察结果。两路都讨论何时何地、阻碍与调整，尊重现实限制和暂停选择。

**检验**：提供一份笼统或跨度过大的示例计划，请本人修订，再检查自己的计划能否说明目标、第一步、安排、阻碍和边界。暴露路径还需说明台阶与所观察的预测。无实际尝试时仅评价计划设计；本人未选择计划时记未观察，不伪造失败或实践。

**课后衔接**：保存路径、计划设计表现与本人选择；后续询问是否尝试及遇到什么困难。课程范围不包含危险挑战、创伤暴露或身体诱发练习。

## 第 6 课 修正我的思维

**目标**：对具体判断检查依据，形成与已有信息相符、允许不确定的说法。

**教学与个人练习**：可以接着第 3 课的本人想法，分别询问支持信息、不同信息和尚未核实之处，再请本人形成愿意保留的表述。承认现实困难，允许没有反证或仍认为原想法有道理。

**检验**：换一个含已知信息与推断的新案例，请本人指出依据和未知之处，再提出与信息相符的解释。评价证据使用及不确定性的保留，不要求乐观，不将模型建议写成本人回答。

**课后衔接**：保存依据检查表现、本人说法与待核实内容，观察哪些提问提供了帮助。第 8 课可以将其作为候选应对技能，由本人选择是否继续使用。

## 第 7 课 睡眠与放松训练

**目标**：根据本人选择，理解一种日常调节方法，并说明可行的使用与调整条件。

**教学与个人练习**：本人选路。睡眠侧重观察习惯并选择一个可调整处；放松侧重了解一种舒适的方法，由本人决定是否短暂尝试并反馈。尊重不愿闭眼、身体限制和不适，不以忍耐或立即放松作为目标。

**检验**：睡眠路径检查能否形成具体的习惯安排并说明如何回顾；放松路径采用复述与情境判断，说明如何使用、何时调整或停止。若不实际操作，记录其理解与计划，不声称观察到操作能力。

**课后衔接**：保存理解表现、本人偏好和条件；实际睡眠、舒适程度与生活使用另待本人反馈。本课限定为一般习惯与舒适放松，不提供睡眠限制、药物或个体化治疗处方。

## 第 8 课 再遇困难时的准备

**目标**：将前面的学习整理成可回看、可调整的应对准备。目录可保留“预防复发”名称，不预设本人有疾病、曾治愈或已复发。

**教学与个人练习**：按本人选择回顾前课，区分学过、尝试过和本人认为有帮助的技能；整理早期信号、第一步、备用做法、可获得的支持与回看安排。缺课或缺少实际使用反馈时，明确相应信息仍未知。

**检验**：进行一个与本人目标相关的情境演练：“下次再遇到类似困难，先做什么？第一步做不到怎么办？”观察能否选择技能、说明理由和调整计划，不以列出更多课程名称作为成绩。

**课后衔接**：保存应对计划、情境演练表现和仍需练习处；后续是否实际使用及感受须另行收集。参考过的前课成果不等于其中每项技能都已使用或有效。

## 检验后的学习结果

结构化是表达形式，可以保存学习结果，也可以保存 Reflexion。学习结果与解释假设保持不同身份，至少包含以下信息：

| 内容 | 含义 |
| --- | --- |
| 本课目标与任务 | 指向哪项技能，题目、路径和评价依据是什么 |
| 首次表现 | 原始回答与依据，是否正确、部分符合、需澄清或未观察 |
| 帮助与反馈 | 提示的具体内容和先后，不能仅凭回复次数推断帮助程度 |
| 补练表现 | 新任务、本人回答与变化，保留原首次记录 |
| 本人练习 | 经本人核对的经历、目标或计划及其来源 |
| 本人反馈与选择 | 对课程的反馈、课后安排、拒绝或暂停 |
| 证据范围 | 适用情境、仍未观察的能力和实际使用情况 |

客观分类题可以按预先确定的语义判据评价。个人经历、情绪和偏好依本人报告与核对；用户不接受某个思维模式，不能据此扣分。暂不设统一总分或跨课过关线，课程完成与学习判断分别表达。

## Reflexion 与个体化理解

Reflexion 结合已验证学习结果、真实问答、本人反馈及仍适用的旧反思，形成简短、可审查的分析摘要，并提出下一步指导。它不输出完整思维链，也不改写已确认的本人记录。

| 反思内容 | 要求 |
| --- | --- |
| 表现依据 | 指向具体任务、回答、提示和本人反馈 |
| 解释假设 | 说明本次困难可能在哪里，也考虑题干、讲法或任务跨度等其他解释 |
| 学习支持特点 | 例如本次生活化对照较有帮助，限定观察范围，不直接写成永久能力或偏好 |
| 个人思维线索 | 例如某类本人案例中出现拒绝解释；保留情境、本人核对与不确定性，不作诊断或人格判断 |
| 后续调整 | 明确下一次先复习什么、如何改变提示或使用什么案例 |
| 核对办法 | 用什么新任务或本人反馈检查假设，以及何时修改或撤回 |

示例：本人能够描述“难过”，但在分类题中将其选为想法，经一次提示后修正。可提出“本次可能尚未熟悉术语与日常表达的对应”，同时考虑题干是否含糊；下一课对照“我想到什么”和“我感到什么”，再用新题减少提示复核。不能据此写成固定的能力缺陷。

反思中个人线索的深入程度来自证据之间的联系，不来自更强的标签。单次任务先形成局部假设；多个案例也须考虑问题、人物、时间和情境差异。后续不同证据可修正旧理解，不将未知的策略效果自评为成功。

跨课使用时，课程定义决定技能目标，学习结果提供表现依据，Reflexion 提供可修正的建议。继续遵循同一参与者、来源可追踪、版本与授权规则；只传递必要且适用的信息，不默认为可读取前课完整对话或全部反思。不让反思替本人选分支、确认、完成或强制跳课。

原始 Reflexion 主要用于 Agent 根据任务反馈改善后续决策；将其扩展到课程相关的个体化理解，需要单独评价来源、合理性、可修正性和指导收益。

## 相对 004 基线的目标差异

以下表格保留设计对照。第 1 课四题、目标、学习结果与情境假设现已接入；其余课的新任务及跨课反思采用仍待实现。

| 项目 | 当前运行基线 | 本规格的目标变化 | 预期作用与验证 |
| --- | --- | --- | --- |
| 第 1 课教学 | 示例回答与四要素记录，完整四题未保留 | 恢复四题检查、明确学习目标建立 | 检查概念辨认；区分首次、提示与补练表现 |
| 第 2 课教学 | 三栏记录为主，作业回顾可交流，完整三题未保留 | 恢复明确作业回顾与三题复习，增加联系理解和迁移检查 | 明确与第 1 课的分工，观察独立应用 |
| 自我评分 | 当前允许跳过近况评分，不收相信程度与情绪强度 | 教学细化时单独确定各评分是否保留、是否可跳过 | 保留自我观察的原意，不混用为知识成绩 |
| 第 3—8 课 | 引导材料、本人记录、计划或回顾 | 增加各课不同的检验任务与评价依据 | 观察推断辨认、情境判断、计划设计和技能选择 |
| 正式学习结果 | 确认的案例或计划，少量示例回答证据 | 增加任务表现、帮助程度、反馈、补练与证据范围 | 区分课程记录齐全、独立理解和实际使用 |
| Reflexion 时机 | 可配置课内触发与独立课后复盘 | 以检验后的阶段汇总作为新设计主要节点 | 对齐训练反馈；调用拓扑和额外频率后续另定 |
| Reflexion 内容 | 当前主要为短教学观察与指导策略 | 增加带依据、情境和核对办法的学习支持特点与个人线索 | 支撑个体化指导，检查错误归因和旧假设撤回 |
| 课程联系 | 授权案例字段与第 8 课多课回顾 | 增加适用且获准的学习进展和指导建议 | 后课解释为何复习或调整，不能伪造能力和偏好 |

原版与目标版均不是正式心理测验。第一次课后答对只能支持当下任务表现；训练带来的提升需有可比的先前表现和后续观察，生活作用和临床效果另需相应证据。

## 验收与后续细化

- 每课能说明目标、引导、个人练习、检验、反馈及课后衔接，新增或删减均有内容对照。
- 第 1 课四题和第 2 课三题复习可追踪；检验案例与引导案例分离，提示不冒充独立完成。
- 第 3 课有依据地拒绝分类可以体现技能；第 4 课保护现实边界可以是合理选择。
- 第 5 课两路、第 7 课两路均有各自的任务、判断依据和未观察状态，不以计划完成声称生活改善。
- 第 6 课允许没有反证和保留原判断；第 8 课检查技能选择与调整，不以完成课数推断效果。
- 学习结果有任务与回答依据，个人记录保留本人核对；Reflexion 的解释与事实分开，能追踪后续是否采纳及是否修正。
- 反思失败不撤销已保存的本人记录和学习结果；补练、拒绝和未检验有各自状态，不用假分数补齐。

后续细化包括题目与判据、帮助程度定义、目标数量、各自我评分的角色、允许的复习与补练次数、用户查看或核对反思的呈现方式，以及跨课建议的采用规则。它们不改变上述已确认方向。

测试对象须分开：本规格中的检验评价学习者在课程任务上的表现；[004 专项理解测试](../004-eight-lessons/understanding-tests.md)评价 Agent 是否正确理解、记录和指导；工程回归评价程序行为。三类结果不能互相替代。
