# 第 1、2 课结构化教学试用规格

状态：2026-10-15，按本次用户授权实现。范围只含当前两课，保持 Daily Chat 与历史数据兼容。

## 体验与教学目标

- 以自然对话学习，用六个阶段表示签到、示例探索、个人练习、记录确认、课后安排、收获回顾。
- 第 1 课辨认事情、想法、情绪、行为，形成一份由本人确认的四要素记录。
- 第 2 课练习事情、想法、心情的区分，形成一份由本人确认的三栏记录。
- 课程结束、一次引导练习的表现、生活中实际运用分别记录；不推断诊断或永久掌握。
- 可跳过评分、拒绝课后安排、暂停及恢复。安全暂停只能退出查看，不能用普通恢复按钮继续。

## 模型与程序的边界

- 普通教学轮次最多一次模型调用，第 2 课最多 600 输出 tokens。返回 JSON 正文、带本课消息来源的摘录和阶段建议。
- 程序校验字段、来源、精确摘录、允许的阶段变化；模型不能直接修改完成、确认、权限和跨课授权状态。
- 必要练习缺失时不进入记录确认；确认和完成由用户显式操作，语音可使用对应明确指令。
- 记录确认时冻结四要素/三栏与消息来源。模型后续输出不能覆盖确认记录。
- 畸形结构化输出不推进、不写入成果，原始用户输入与失败审计保留；重试使用原请求输入，避免重复显示。

## 记忆与课后反思

- 第 2 课仅可承接同一参与者、当前版本、已结束且本人已确认的第 1 课摘要；本人可接受或拒绝。模型不读取其他课程原文或角色语境卡。
- 读取或接受时重新验证来源。来源删除、版本不符或非本人时不可注入。
- 课末一次独立反思：基于可定位的对话与本人反馈，输出有来源的教学观察和待验证建议。它是教学改进假设，不写入本人事实或诊断。
- 反思具有独立审计、成功/失败状态与手动重试；失败不撤销已完成的课程。默认仅展示和保存，不自动将反思建议用于后课。
- 所有状态、摘要、摘录和反思复用现有 AES-GCM 加密列，不新增数据库表或明文字段。

## 页面与验收

- 当前阶段可见，学习记录随对话出现，重要记录可修改并确认；停止显示伪造的百分比掌握度。
- 展示“曾完成一次引导练习”，不写“已完全掌握”。课末可回看本人记录、安排与反思状态。
- 第 2 课承接摘要必须显式选择。历史版本只读，有入口开始新版。
- 提供隔离的本地离线体验：明确标注规则演示，不调用外部模型，不使用真实数据库。
- 回归覆盖：跳阶段/伪造来源被拒绝、显式确认、课间权限和删除、暂停/安全、幂等/加密/错误审计、反思失败与重试、页面和完整两课流程。

## 实现顺序

1. 课程阶段与结构化契约、独立版本；2. 来源校验与状态机；3. 课间摘要与反思审计；4. 页面体验；5. 隔离预览与验证。
