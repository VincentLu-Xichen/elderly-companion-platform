# 第一课反馈恢复与自然回顾

2026-10-18，用户明确授权修复实际体验问题。基线为未提交的014第一课7.0，不覆盖其工作。

## 范围与职责

1. 突发互动反馈：候选规则只召回，LLM判断意图、范围及合法动作。检验模型也可报告规则漏检的反馈；同条消息不再做第二次专门反思。检验负担不记错、不记概念提示；明确不想继续多题时停止剩余检验，保留已答、将未答标未观察及来源，进入回看。仅嫌回复长不自动跳题；暂停与停止练习分别处理。
2. 错字：依据上下文理解明显错字/口语（如白跑了一堂），原始消息与四要素摘录保持原文。模型的自然回顾可表达明确原意，歧义影响判断时澄清，不做无条件替换、不改变评分的严格规则。
3. 回顾：从已校验的当前案例生成一句至两句LLM总结，引用当前字段来源；虚构人物身份固定，缺失不补造，不把未提供评分称作用户留空。不推断因果循环/能力/满意度。侧栏保留原话核对。摘要按案例内容指纹缓存；失败留审计、给中性核对出口，不回退成逐字段念表格。
4. 反思分层：事件Reflexion继续复用独立加密表，保存观察、原因假设、其他解释、作用范围、立即动作和待核对效果。每课结束仍固定调用独立LLM，现有结构化observations/suggestions/hypotheses及来源、核对方法保持，不因局部投诉取消。案例自然回顾不是Reflexion，不写成长期偏好。
