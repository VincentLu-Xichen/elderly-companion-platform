# 自然反馈事件 Reflexion 与独立记忆

## 目标与授权

用户于 2026-10-18 要求实现：强烈的自然互动反馈触发动态 LLM 判断，保存结构化 Reflexion 到独立存储。无需选择“直接看解释／继续聊”。本次不重新设计课末总结：保留已有课程完成后异步 LLM 复盘，新的课末反思协议待讨论。

旧版 6.4 用整句规则或按钮写规则记录；当前目标改为“候选检测不做最终归因 → LLM 判断对象与原因 → 即时回应 → 持久化独立指导记忆”。紧急指互动优先级，不是医疗风险等级；原有高风险暂停先于模型调用。

## 场景与边界

- “你烦不烦，一直追问”：结合当前阶段及最近对话判断是否针对 Agent。若成立，保存原话、观察、原因假设、替代解释、白名单指导及作用域，直接回应，不改学习事实、不消耗练习答题／澄清次数、不自动推进阶段。
- “他说我烦不烦”“我没有嫌你一直追问”：可能被候选规则捕获，但必须由 LLM 拒绝错误归因；拒绝后正常教学，不能保存有效偏好。
- 普通短答、单独情绪描述不增加反思请求。仅明确互动负担／催促／表达偏好相关候选才额外调用。候选规则覆盖有限，不声称识别所有情绪表达。
- LLM 失败、来源无效或输出越界：记录失败审计，给出不带偏好推断的短回应，不更新记忆，不伪装为成功反思。无自动重试和隐藏修复调用。
- 所有八课均能处理反馈事件；事件轮使用一次专用模型调用生成结构化反思与即时回应，普通教学轮不增加调用。
- 跨课只传适用的紧凑互动指导，不复制前课对话或课程事实。局部不满默认仅当前课；明确跨课偏好才可跨课使用，新反馈覆盖旧指导，来源删除后不再检索。

## 数据与审计

用户已确认采用同一数据库的独立 `interaction_reflections` 表。需参与者隔离、加密载荷、幂等、来源关联、删除一致性和重启持久化。模型不得决定用户 ID 或数据库键。模型输出严格校验，来源必须来自本轮真实用户消息。

指导只允许有限枚举：篇幅 short/standard、追问 reduce/standard；模型生成原因假设不能成为用户能力标签或任意系统指令。检索后由教学模型与程序回复共同采用，单独记录注入和实际呈现，效果始终待测量。

## 验收

1. 自然反馈经真实模型接口而非按钮配置进入 Reflexion；合成模型单测明确不等于真实模型语义验证。
2. 正向、否定、转述、普通情绪、模型失败、无效来源、安全暂停分别覆盖。
3. 记录加密、同键重试不重复写入、用户隔离、局部／跨课检索、删除来源失效及新指导覆盖可验证。
4. 第 1 课程序回复确实采用指导，不再用 `reflection_created` 单一标记冒充实际采用或有效。
5. 课程版本升版，旧会话只读；数据库迁移空库升级通过；公共与课程回归通过。
