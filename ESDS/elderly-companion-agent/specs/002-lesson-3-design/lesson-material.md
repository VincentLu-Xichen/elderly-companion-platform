# 第 3 课场景材料

日期：2026-10-15。状态：课程配置素材，尚未实现。逐轮反思、数据契约和 Prompt 以[架构](spec.md)、[契约](contracts.md)和[Prompt](prompts.md)为准。

本文件集中保留课程目标、示例和成果要求，作为 `LessonSpec` 的素材；用户当前重点是计算机系统设计。参考：[CCI 课程资料](https://cci.health.wa.gov.au/Resources/For-Clinicians/Depression)、[思维模式说明](https://www.health.wa.gov.au/sitecore/content/Healthy-WA/Articles/U_Z/Unhelpful-thinking-styles)。素材为项目自编设计，尚未验证教学效果。

## 1. 教学目标与边界

第 1 课练习分开看事情、想法、心情、做法；第 2 课练习用三栏表达经历；第 3 课追问：**这条想法里，哪些是已经知道的，哪些还只是猜测？**

本课目标是完成一次辨认尝试，能说出自己留意到的线索，或明确表示依据不足。不要求背诵类别，不要求接受 Agent 的判断，不要求变得乐观。系统记录“完成一次引导下的尝试”，不能据此写“已掌握”或“心理状态改善”。

建议先提供四种常见模式，用口语解释后再给名称：

| 口语解释 | 可选术语 | 自编教学例子 |
| --- | --- | --- |
| 还没问清楚，就确定别人怎么想 | 读心式推断 | “他没回复，就肯定是在嫌我烦。” |
| 把最坏的可能当成必然结果 | 灾难化 | “这次忘了带钥匙，以后肯定什么都做不好了。” |
| 从一次事情推到所有时候 | 以偏概全 | “这次没聊好，我每次跟人聊天都会失败。” |
| 只允许全好或全坏，忽略中间程度 | 非黑即白 | “只要有一点做不到，这次努力就全白费。” |

分类可以重叠，一次只讨论与本人例子最相关的一种，最多展示两个候选。例子与中文措辞为本项目自编；四类的选择和数量属于降低教学负担的设计假设，尚未经过学习者评估。

遇到现实中的拒绝、伤害、困难或有证据支持的担忧，先承认事实，再讨论解释中的不确定性；不能为了完成分类而否认经历。持续困扰或风险按现有支持与安全暂停机制处理。

## 2. 六阶段课程与可见成果

| 阶段 | 学习者体验 | 程序需要的记录或条件 |
| --- | --- | --- |
| 近况与回顾 | 可跳过评分。展示可引用的前课记录，选择“接着这条想法”或“换个新例子” | 来源校验通过，且有本人的本课引用选择；不选择不向模型注入 |
| 一起看个例子 | 对比“朋友没回复”和“他肯定嫌我烦”；问两句话中哪句还需要更多信息 | 留下一次示例回答；说不明白时换口语解释，不靠同意 Agent 通关 |
| 试试自己的经历 | 先检查事情、想法、心情是否仍准确，再问“您当时怎么确定这一点的？” | 新例子逐项收集三栏；引用例子先确认适用性。随后记录本人对推断依据的表达 |
| 核对学习记录 | 查看三栏、原话依据和可选分类，能修改、选择不确定或不认同 | 三栏完整；本人已对分类作选择，包含不确定/不认同；整份记录显式确认 |
| 选择课后安排 | 可选练习：留意一次“我知道的”和“我猜测的”，也可不安排 | 本人接受或拒绝，不以安排作业作为成绩 |
| 回顾本课收获 | 可留反馈后完成，看到本人的记录与复盘状态 | 记录已确认、课后安排已选择、本人显式完成；复盘独立运行 |

“本人对推断依据的表达”可以是“我还不确定”“这句话确实是对方说过的”。程序验证来源与操作是否存在；语义是否构成某种思维模式仍是可被纠正的判断。不能用字段齐全来证明辨认正确。

对话示例（以下人物、消息及记录均为虚构）：

> Agent：上次您记录的是“女儿没有回电话”，当时想到“她肯定不在乎我”。这次愿意接着看这条想法吗？也可以换一件事。
>
> 学习者：可以，事情和心情没变。
>
> Agent：当时有没有什么具体信息，让您觉得“肯定不在乎”？
>
> 学习者：没有问过她，我是看到没回电话就这样想了。
>
> Agent：听起来，您也注意到还没问清楚。我们有时会把对别人心思的猜测当成确定结论；您觉得这次像这种情况，还是有其他情况要补充？

如果学习者回答“她亲口这样说过”，Agent 应承认新信息，撤回不合适的候选；如果回答“不想被分类”，则保留原话并继续核对。不能反复劝本人接受标签。

建议带走的记录卡包含：事情、当时的想法、心情、本人对依据的说明、对可选分类的选择、本人确认状态。页面把“本人原话”和“Agent 提供的可能解释”分开显示。
