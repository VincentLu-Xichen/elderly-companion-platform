## 当前后端怎样阅读

1. **catalog.py**：唯一活动课程注册和课程版本。
2. **router.py → services.py**：现有页面/API入口，检查归属/同意/版本，处理幂等、加密消息和审计事务；流式仍复用streaming.py。
3. **runtime.py**：统一安全、互动反馈和控制动作；第一课调用blueprint.py、teacher_flow.py、learning_check.py、navigation.py；第二课交给lesson2_flow.py。
4. **agent.py／prompt.py／schemas.py**：模型调用、角色指令和结构化校验；本轮未引入多Agent或新模型路由。
5. **interaction.py／interaction_memory.py／reflection.py**：即时反馈、独立互动记忆及独立课末复盘；memory.py只保留第一课到第二课的授权引用。
6. **history.py**：已退出活动目录的课程快照显示，不含已删除的教学脚本。历史完整成果与未知字段仍在加密快照及管理员导出中；旧技能图/专属教学控件不重建。
