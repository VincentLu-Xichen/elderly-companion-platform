# 八课完整工作流规格

> 本规格保留共享基线。第 1 课已按 [005 教学练习与检验设计](../005-course-learning-design/spec.md)及 [008 阶段重点与收束](../008-lesson1-stage-focus/spec.md)扩展为 `6.4-learning-check` 九阶段；第 2—8 课仍按本规格。下文六阶段及旧第 1 课版本是原基线，不代表新增检验已覆盖八课。

日期：2026-10-16。用户授权：沿用前三课的推进节奏补齐八课，后续再做专项理解测试与迭代。本轮交付完整课程配置、材料、数据依赖、交互和工程验证，不将离线规则演示当成理解或教学效果证据。

## 保留与版本

沿用六阶段、JSON Object + Pydantic + 原话来源校验、四种反思策略、本人确认、加密、幂等和独立课后复盘。普通教学一次调用，触发时三次，按钮操作不调用模型；触发策略优劣继续待实验。

公共字段契约与分支行为变化，版本升为 `course-guided-v3` / `guided_cbt_v3`；第 1、2 课 `5.0-eight-lessons`，第 3 课 `2.0-eight-lessons`，第 4—8 课 `1.0-eight-lessons`。既有会话保留只读，不自动迁移旧确认记录或混用旧版本成果。前三课的教学任务不变。数据库表结构不变。

成果契约为 `course-artifact/2`，区分 learning_record / action_plan / coping_plan，路径与引用来源单独保存，`application_status=not_measured` 不把整理成果当成真实运用效果。

## 新课与成果

| 课 | 任务 | 必要本人记录 | 成果联系 |
| --- | --- | --- | --- |
| 4 相反行为 | 看见情绪推动的行为，判断是否有帮助，考虑可行替代 | situation / emotion / behavior / action_fit / alternative_action / safety_note | 优先第 3、2、1 课；只显式采用相同语义的已有字段 |
| 5 行为激活/行为暴露 | 本人选择路径，整理一项小步计划 | 两路共 situation / first_step / when_where / barrier_plan / safety_note；激活加 activity_goal，暴露加 feared_prediction / graded_steps | 优先第 4、3、2、1 课；不把计划写成已执行 |
| 6 修正我的思维 | 检查支持/不支持信息，形成更平衡且可保留不确定的说法 | situation / thought / emotion / evidence_for / evidence_against / balanced_thought / next_step | 优先第 3、2、1 课三栏，不用行为计划伪造想法 |
| 7 睡眠/放松训练 | 本人选睡眠习惯或舒适放松，形成小步安排 | 共 first_step / when_where / safety_note；睡眠加 sleep_pattern / sleep_habit，放松加 stress_cue / relax_method | 可参考第 6、5、4 课摘要，必要字段从本课回答取得 |
| 8 预防复发 | 回顾可用技能，整理再遇困难时的应对与支持 | early_signal / helpful_skill / response_plan / support_plan / review_plan | 可授权回顾同参与者当前版本第 1—7 课每课最新已确认成果；缺课仍可独立完成 |

第 4 课不要求机械地做与情绪相反的事，允许暂不行动；第 5 课只整理本人愿意考虑的低风险日常计划，不实施创伤/身体诱发暴露或危险挑战；第 6 课不强求积极、不捏造反证；第 7 课不提供睡眠限制、药物或个体化治疗处方，放松可随时停下。停止/暂不行动/尚无依据可按本人原话保留；完成一份计划不代表做过或有效。

## 分支与引用

第 5、7 课在示例探索前显式选路径，模型不能代选。未选不能推进个人练习或确认。选择、返回重选均为审计中的本人操作。活动中重选先清除旧路径记录、确认、学习证据和课后选择，重开示例；完成后只读。路径保存在状态、确认快照与成果中，任务标识与反思适用性包含路径。

单课授权摘要和实际采用继续分开：只复制本课需要且语义相同的情境字段，保留来源成果/字段和本课采用消息；不复制计划为已发生行为。第 8 课提供多份紧凑摘要，统一显式接受/拒绝；每次使用复核各来源，失效来源移除，全部失效则撤销引用。模型不读取前课原文、未确认草稿、角色语境或整段反思。第 8 课成果列出当时可用的已授权参考成果 ID，不宣称每条都已实际应用。

开放八课目录。页面展示本人路径、来源、计划字段和明确重选操作；只在隔离体验提供示例与调试区。示例每轮至多填四个待补字段，沿用教学输出至多四条摘录的契约。

本轮验证所有课程/四条分支可独立完成，八课连续引用与回顾、分支重选/防越权、无前课、引用删除/版本/归属、失败不推进、反思适用性、导出与旧版本只读；检查电脑/手机主要路径及语法。

另建专项理解测试清单，涵盖真实模型摘录、模糊回答、否定/转述、拒绝、事实/推断、分支混淆、现实风险、跨课引用与反思消融。该专项待后续执行，本轮不新增真实模型评分结论或临床结论。
