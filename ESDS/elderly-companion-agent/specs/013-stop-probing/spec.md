# 第一课：停止追问并保留当前事件

用户报告重复追问、反馈失败冷漠、案例来源混用及固定回复突现，并要求修改。本切片属于 R-003/I-003/I-004。

- 抱怨追问方式与拒绝个人经历分开判读。前者不能设个人边界、不能换案例、不能清空已说内容；拒绝整个案例仍走 011 的确认/替代路径。
- 增加 response_type（acknowledge_adjustment/review_current_case/neutral）、tone（standard/polite），follow_up 增加 stop。明确不再追问时保留当前案例和字段，剩余项记作本次未收集、进入待本人核对；不确认、不填造答案、不当理解差。
- 强烈反馈简短承认负担、礼貌道歉、明确停问，再回顾已有内容，不解释系统内部状态，不机械问剩余字段。反馈失败也礼貌停问，不因风格判断失败设置个人拒绝 recovery；保留失败审计且不造长期记忆。
- 新版不常驻显示逐字段“想不起/不谈”按钮；既有 API 和旧版兼容保持。核对、暂停和自然语言拒绝可用。
- 教学输出增加案例来源判断。虚构练习不能接受另一件个人经历当案例答案，拒绝不一致的提取并清楚承接，不把新个人事实标成虚构人物。
- 无模型增量的固定回复在最终结果保存后逐步显示；已有 LLM 流式保持。支持减少动态效果、后台页即时显示，控制总展示时间，无新增模型调用，不将动画伪称实时模型生成。
- 第一课升 6.8；旧会话只读，旧风格记忆默认兼容，无数据库迁移；其他课不升版、不扩大为整套课程重写。

验收覆盖：抱怨追问保留同例/字段并进入核对、普通风格不乱推进、隐私拒绝继续适用、失败无换例/记忆、否定转述不误判、后续不重复追问、混入新个人故事不作虚构答案、UI按钮隐藏及固定回复渐进显示、原检验/本人确认/幂等/隔离继续通过。分别报告离线、有限真实 LLM 与网页证据。
