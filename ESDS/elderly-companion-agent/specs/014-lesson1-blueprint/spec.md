# 第一课对齐老师蓝图

依据：用户指定的《CBT数字干预课精卫合作版-第一节23-10-18.xmind》及已确认实施方案。原文件和提取图片不纳入仓库。

## 教学路径

八课介绍与心境检查 → 选择一件困扰、情境教学 → 同例想法及相信程度0—10 → 情绪及强度0—10 → 实际行为 → 个人化模型、相互影响与新看法 → 本人核对 → 原场景四题逐题反馈 → 整套课程一至五项目标、修改与确认 → 可选四要素日记 → 显式结束及独立课末反思。

保留九个导航阶段，用子步骤承载评分和关系回顾。已说过的内容不重复索取；每项初次回答后最多一次澄清，缺项留空。拒绝、同例停问、询问边界、独立加密记忆、流式与自然语言导航保持有效。普通评分/关系回答不自动触发互动反思。

## 对照与取舍

恢复原稿两项评分、同例概念教学、动态模型、关系回顾、多项课程目标和逐题反馈。保留新版自愿出口、补练、来源与确认门禁。原练习“拼命想和人说话”改为“不断找话题，接着和对方说话”，使行为明确为已发生动作；其余保持打招呼、未想到回应、担心关系、紧张的考点。

评分为明确用户报告，不猜测、不截断；0与缺失分开。虚构角色只记录材料中明确给出的评分；无评分时跳过，不询问用户代作个人评分。更改想法/情绪后对应旧评分失效，案例切换归档并清空相关数据。相互影响是教学模型，不能断言用户存在未经确认的因果循环。

结构化结果保留原始回答、帮助与逐题反馈的暴露信息，后续题不冒充完全独立测量。目标保留原话来源，草稿修改撤销旧确认，最多五项，超出邀请合并而非截断。评分不跨课传播；仅确认目标提供紧凑摘要，来源、版本、归属和授权规则不变。

目标修改既支持完整替换，也支持明确编号的局部修改；局部修改保留其余条目和原始来源，不从新消息伪造旧来源。编号、原话、数量不合法则不采用。普通教学报告的拒绝优先于案例选项；案例选择草稿与练习草稿同样不提前流出，正式回复保存后渐显。

## 验收
