# 最小反馈适配试用

日期：2026-10-18。基线第 1 课 6.3，当前 6.4 已实现。用户要求减少想法堆叠，先最小化执行观察效果。见[实现与验证](implementation.md)。

## 唯一验证问题

第 1 课个人练习中，用户明确表示连续追问或解释造成负担时，系统能否保留反馈、给出选择，并实际减少追问？不重设计八课，不改题库、评分、模型温度或反思频率。

## 最小行为

1. 个人练习提供“我想少解释一点”入口，另支持少量整句明确反馈，如“一直让我解释，感觉像审问”。只匹配明确整句，不能从短回答、情绪、时长或事件里别人说的话推断反感。
2. 收到反馈后，不把它记成个人想法或心情、不消耗澄清次数、不自动跳阶段。简短回应，提供“直接看解释／继续聊”。
3. “直接看解释”只展示当前概念的简短说明，不编造用户经历、不自动填字段、不自动跳过；可随后暂留当前项或继续。“继续聊”恢复当前一个问题，并省去重复引导语。用户直接输入练习回答也可继续，不强迫按钮选择。
4. 保存一份局部结构化反馈记录：原话及消息来源、可能原因、其他解释、选择及来源、有效行为参数、待核对状态。原始反馈事实与原因假设分开，效果始终为未测量，不能把点击继续记成满意或有效。
5. 参数仅 `reply_length=short` 与 `follow_up=offer_choice/one_question`，只对本次案例的个人练习生效。核对、独立测试和其他课不自动沿用。记录核对仍完整展示用户原话，不为简短而截断证据。
6. 当前先用程序生成可审查的反馈记录与适配建议，明确标为规则派生记录；不将其宣称为新完成的 LLM Reflexion。既有课内 Reflector/Actor 策略不变；课后复盘可将该记录及原消息作为依据。

## 数据与兼容

沿用加密状态、Trace、幂等、CSRF、归属与串行处理。新按钮零模型调用；普通回答调用边界不变。旧课程只读，不迁移、不删除用户进度，不读取输出或修改真实密钥，无表结构变化。第 2—8 课版本和行为不变。

## 验收

- 明确反馈触发选择，普通叙述/转述/否定不触发；按钮可覆盖未匹配自然表达。
- 反馈不进入四要素、不会消耗澄清机会；两条选择都产生可见且有区别的行为。
- 继续、直接回答、暂留、刷新、修改、阶段切换保持正常，适配不泄漏到测试或跨课。
- 保存反馈与选择来源，课后复盘可读取；既有独立反思仍不得改用户事实。
- 运行隔离回归和页面验证，结果只证明链路可执行，体验收益由用户随后反馈验证。
