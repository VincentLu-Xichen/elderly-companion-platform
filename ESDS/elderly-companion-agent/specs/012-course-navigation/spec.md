# 第 1 课：衔接、输入与自然语言推进

用户已在批注“调整一下”明确授权。属于 R-003/I-003，实施范围为第 1 课三个体验问题及开场说明。

- 单项暂留回复明确上一项、下一项；虚构案例按钮、状态与提问使用辨认语境，保留旧个人经历用语的兼容解析。
- 聊天提交先保存独立请求快照，立即清空输入/字数；失败保留原请求同键重试。点击控制按钮不得清除未发送草稿；成功重试也不能清空后来输入的新草稿。
- 开场说明侧栏记录、必要核对及可选步骤；不承诺任意聊天可跨过任意阶段。
- 只在第一课 learning_goal/plan/summary 使用一次非流式 LLM 结构化判读自然语言。明确跳过目标且不安排课后练习可连续两个动作至 summary；单说“完成了”在有目标草稿时澄清确认/跳过，在无草稿时澄清目标意图，不当目标正文。真实目标仍形成草稿待确认。
- 白名单动作及每步消息证据、合法阶段由程序验证；整组在副本校验后采用，拒绝部分执行。finish 仅能在进入本轮前已为 summary 时请求，不能越过练习核对或检验，不能把完成当掌握或生活中已执行。
- 先处理现有安全/互动边界；新导航不产生互动偏好记忆。失败审计且不改变阶段，不自动兜底跳过。
- 第一课升为 6.7；旧会话只读。无表结构迁移，其他课版本和独立检验题目不变。

验收：个人/虚构暂留话术及来源；即时清空、失败重试、新草稿保留；目标正文/含糊完成/明确跳过/确认草稿/合并两步/非法跨阶段/失败/幂等；离线回归、真实模型少量合成案例和浏览器体验分别报告。
