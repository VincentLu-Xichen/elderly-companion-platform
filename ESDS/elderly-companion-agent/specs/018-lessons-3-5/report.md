## 课程逻辑：连接技能，不强制连接同一件事

第三课教“辨认一种表达方式”，第四课教“判断是否考虑不同回应”，第五课教“排序并选一个可考虑的起点”。三课都先讲方法、做示范、共同练习，再邀请应用。用户可以换事件、用虚构案例或暂留，不能把课堂变成Agent替用户连续分析一个困扰。

老师八课总纲明确第三课识别歪曲思维、第四课相反行为、第五课两路回顾三栏/相反行为并做难度排序。当前没有三份详细原稿，因此四类选材、具体例子、子步骤和定性难度描述为本版设计，不称老师原文。材料参考[CCI官方信息页](https://www.cci.health.wa.gov.au/Resources/Looking-After-Others/Information-sheets)，不复制其整份教材，也不以网站资料代替教师确认。

### 三课分别新增了什么

**第3课**原版已有事实/推断示例、依据字段、四类候选及本人核对；但正常流程主要是一个例子后填写记录。本版将四类短教学、共同练习、应用、候选核对拆成可见活动。预期用户能够先理解方法再使用；本轮没有验证脱离帮助后的独立能力，也不声称四类已覆盖老师完整材料。

网页沿用“看见想法中的习惯”的课程名称，本课承担总纲中“识别歪曲思维”的教学任务；名称不表示对用户稳定思维特征的诊断。

**第4课**原版已有作用、替代和边界的Prompt/字段，容易呈现为Agent询问后给建议。本版先解释三个时间身份，新增action_urge与实际behavior分开，示范适用判断，再由用户考虑回应。等待、边界、支持等回应可能合适，不统称为相反行为，不预设必须改行为。没有本人实际尝试反馈时，只能报告讨论和计划。

**第5课**原版已有两路选择、小步计划，只有暴露含graded_steps。本版两路都显式回顾方法、展示排序示范、共同修订过大的安排，再进入本人或虚构应用。激活新增排序。排序保留连续原话及来源，**没有将自然语言自动转成数值难度或结构化逐项评分**；既有字段记录的结构化身份与难度文字分开。第一步由本人表达，不由程序选择最简单一项。

## 不顺利时怎样收束

- 已说多项一起整理，缺项最多一次帮助/澄清；再次不明记not_observed，明确拒绝当前项记withheld，不写成能力差。
- 明确不做整个应用活动，可一次暂留所有未表达项，仍需本人核对；不能要求逐项点击七次才能退出。
- 拒绝个人经历使用既有一次范围确认与独立边界记忆；长期边界只在明确确认后采用。虚构角色、材料、排序和计划均标fictional，不能成为用户生活摘要。
- 抱怨追问停问并保留同一case_id和已说内容；没有补到的暂留，不切新事件继续问。共同练习中的停问只收束该活动，不自动暂停整课。
- 只有明确暂停才暂停，恢复回原子步骤。当前强风险词安全暂停规则继续沿用，用户此前暂缓的语境细化不在本轮改。
- 记录修改后撤销确认并回应用。第五课换路归档旧路径/活动，撤回记录、确认、课后选择及活动反思，生成新案例身份；完成后不能换路。
- 模型结构化/来源失败沿用事务回滚和失败审计；不静默把假数据补进记录，不发隐藏修复请求。互动判读失败先暂停当前询问，不写成长期边界。

## 程序与数据流程

```text
网页发送消息/操作
 → 原FastAPI同意、归属、CSRF、幂等与串行检查
 → 原服务先保存用户消息及pending审计
 → runtime安全/暂停/已有互动候选判读
 → skill_flow按当前课/路径/子步骤分派
    按钮：合法动作校验，零模型
    聊天：一次skill_turn，输出回复、意图、来源化字段及可选候选/反馈
 → 白名单、连续摘录、当前来源、案例身份和动作校验
 → 更新副本状态；需要时按冻结的原四种任务反思策略运行
 → 同事务保存回复、加密状态、独立互动记忆及审计
 → 原消息流result，最终回复渐显；临时草稿不是保存成功
 → 明确结束后独立固定课末LLM，成功/失败另审计
```

核心在[skill_flow.py](../../cbt_course_llm_freeform/skill_flow.py)，可见材料在[skill_content.py](../../cbt_course_llm_freeform/skill_content.py)。它复用外层六阶段，但各课子步骤独立。普通skill教学不提前流出可能被程序校正的草稿，保存后的最终回复沿用前端渐显；若原任务反思触发，仍支持最终Actor流式。没有将渐显声称为实时模型token生成。

原消息端点不新增。响应新增兼容的skill_lesson（子步骤/材料/活动/来源/暂留/排序），动作白名单增加continue_skill与skip_skill_activity。第四课action_urge、第五课激活graded_steps及新状态存在原加密字段，无表或迁移；其他课required_fields保持原样。

本人确认的部分记录可带明确暂留进入成果/摘要，避免UI允许跳过而后台无法完成。课间仍检查同用户、版本、完成、确认和授权；只沿用合法情境，当前字段来自本次表达。虚构成果不能导入个人经历。旧第三至五课只读，其他课版本不变。

### Reflexion的职责

事件Reflexion继续通过专用LLM理解反馈，独立表保存观察、假设、其他解释、范围与本次调整。自然教学也能报告漏检反馈，共享判读结果避免同一消息重复判断。新课反馈Prompt明确本课任务，消除拒绝后继续问“四部分辨认”的遗留指令。

课末固定LLM增加活动、帮助/暂留、当前来源、排序/计划及候选态度上下文。observations是观察，hypotheses保留其他解释和核对建议；不从不确定、拒绝、评分或结束推断能力/满意度/疗效。**applied仍为false**。现有明确跨课询问边界/风格可以影响后课，不等于课末教学假设已自动采用。
