# 前两课可复用评测数据与基线

2026-10-23，用户明确要求规划、保存可复用测试数据，用当前版本取得输出，形成后续大调整的Git保存指导及可交给Agent的完整推进Prompt。归入R-010／I-005，不实施课程或架构修改。

## 本轮范围

- 将已有E01—E08草稿落为版本化合成案例。先采集6个固定局部案例；整课条件式体验与跨课数据库记忆验证另列，不冒充本轮已完成。
- 案例分开保存人物事实、给模型的实际历史/消息、初始状态构造、程序约束与人工评审标准。答案没有固定文案；评审标准不传入教学模型。
- 使用现有runtime、Prompt、Schema和模型适配器，不修改产品逻辑，不访问用户数据库或旧会话。局部起点为明确标注的合成夹具，不声称通过网页到达该点。
- 当前DeepSeek小样采集：每例一次、最多12次实际API请求、逐次记录、不自动重试。保留失败、原始结构化输出、程序最终回复、前后状态、调用、tokens和耗时。无usage保留未知；不按估算单价编费用。
- 纯合成案例、运行器、说明和报告可进Git；源码快照及原始输出留现有被忽略的test-results。不采集真实个人资料，不读取输出密钥，不重启服务、不提交或推送。
- 固定输入用于局部可比性；整课采用条件式人工角色卡，不能在问题已变时硬塞同一句回答。后续保留未参与调试的变体，不能把同一组案例上的改进推广为普遍效果。

## 验收

同一案例版本可再次运行；每次输出唯一目录、禁止覆盖，记录实际代码指纹与Git脏状态，不能只记旧HEAD。冻结合成起点；记录程序检查与人工待评审分别的结果。默认先检查配置/用例不联网，真实调用须显式开关。真实模型失败不篡改参考输出或改成离线结果。

交付包含本轮实际基线、适用范围、剩余验证、Git保存步骤与完整Agent任务Prompt。保存指导成为后续协作规则；未明确授权时不替用户执行commit/tag/push。
