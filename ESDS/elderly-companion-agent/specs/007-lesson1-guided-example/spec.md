# 第 1 课：示范后换例子引导

日期：2026-10-16。用户授权：修改第二部分“已经讲出答案，又问同一句属于哪类”的教学编排问题。本轮不处理第一部分 invalid_evidence 校验错误。

状态：材料、Prompt、模型 context 和版本已更新；114 项离线回归通过，浏览器已核对新版提问页面。

## 原行为与目标

旧版先完整说明小林案例四要素，随即问已经解释过的“他是不是不愿理我”属于哪类。该问题只是在复述现成答案，且模型可能继续逐项追问同一个示范。

改为：保留小林案例讲解 → 换到小周买菜的新例子 → 只问一个尚未揭示分类的句子 → 用户作答后解释、进入个人练习。这个环节仍为有帮助的引导练习，不作为课末独立检验或掌握证明。

| 环节 | 使用材料 | 呈现规则 |
| --- | --- | --- |
| 示范 | 小林、朋友未回电话 | 可以直接说明四要素及其联系 |
| 引导练习 | 小周、常去的菜摊未开 | 叙述新故事，只问“今天买不到想要的菜了”属于哪类；先等用户回答 |
| 个人练习 | 用户愿意讨论的经历 | 沿用现有原话摘录与本人确认 |
| 课末检验 | 老陈、邻居问好 | 沿用现有四题，不提前带入示范 |

## 数据与接口

新例子按 story/focus_quote/question 配置，并在 learn 的模型 context 中明确当前引导对象。Prompt 区分示范与当前问题，避免再次追问示范答案。没有新增 API、数据库表、阶段、模型调用或检验题。

第 1 课升至 `6.2-learning-check`，旧会话保留只读；不改其他课次版本。现有运行中的 8001 体验服务和用户记录保留，新代码用单独入口体验。

## 验收

- 前端首段先说明示范，再用不同故事提问，提问前不直接解释新句子的分类。
- 模型 context 指向新例子；引导回答仍只记为引导练习，课末四题保持未开始。
- 运行公共与课程回归，浏览器验证新版材料；提供原行为、改动、作用及测试结果。
- 自然语言来源校验问题单独记录，不能把本次材料修订说成第一部分已修复。
