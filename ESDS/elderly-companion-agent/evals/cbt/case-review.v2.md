## 一、怎么审阅这版

- **N1、N2是正常整课路径。** 用户只在Agent实际问到相应内容时提供对应回答；已经说过的内容不为配合流程再说一遍。顺序可以有合理变化，但必要教学内容需要有位置。
- **E开头是局部测试编号。** 每张卡从规定前文单独开始。不要把所有拒绝、纠正和暂停都串到一个人身上。多轮卡内则必须保留前一轮结果，不能每轮重置。
- **表里的“Agent应做”和“记录边界”只给审阅者。** 将来测试时，教学模型只看到真实发出的用户话语、对应历史与合法状态；人物未透露的事实、分支答案和评价要求不能一起传给它。
- **正常路径和局部卡分别报告。** 局部初始状态是人工设置的语义起点，不表示网页已自然到达该处；网页、刷新、跨课保存另有验证范围。
- 你可以直接按编号批注：“这句话不像真人”“这里需要先安慰”“这里应继续问”“这个拒绝只针对本次”。Coding Agent负责补齐来源、状态和后续版本，不要求你决定内部字段。

本稿依据现有`cases.v1.json`、E07变体、整课卡及014/017规格和当前教学材料整理，没有在本轮重新读取老师原始XMind，不将本稿称为原稿的完整重建设计。课程主线保持：第一课区分四要素并回顾、练习、定目标及自愿课后安排；第二课捕捉自动思维和三栏观察。

## 二、评分与互动的共同约定

| 评分对象 | 量尺 | 邀请时需要说明 | 不可混用 |
| --- | --- | --- | --- |
| 上周整体心境 | 1—10分，1非常糟糕、10非常好 | 是上周整体状态，不是表现成绩；可以不评分 | 不能拿来填某件事的情绪强度；0不是本量尺有效值 |
| 某条想法当时的相信程度 | 0—10分，0不相信、10非常相信 | 指明是哪条想法，问当时多相信 | 不能当情绪分数；0与没回答不同 |
| 某种情绪当时的强度 | 0—10分，0不强烈、10非常强烈 | 指明哪种情绪；混合感受时不擅自选对象 | 不能从语气猜分；修改情绪后不沿用旧分 |

**开头可增加的简短说明（候选，未改产品）：**

> 稍后我们可能用分数描述状态、对想法的相信程度或情绪强度。到对应环节我会说明怎么打分，也可以暂不评分。

开头说明不代替具体环节的解释，不意味着用户已经理解或必须评分。正常样本先自然讲述；Agent承接并整理已知内容，再在需要时分别邀请评分。用户没给数字时，先理解新增内容，再适时礼貌提醒当前评分对象。

对于事件中的想法/情绪评分，沿用现有“初问后最多一次针对性澄清，仍不清楚可暂留”的约束；明确拒绝立即尊重，不等次数用完。暂停和停问优先。上周心境未给数字时，应明确邀请1—10分或接受明确不评分的出口，不能从泛泛描述猜一个分数并按已评分推进。

没有提供、想不起、不理解、不愿回答、投诉追问、暂停课程是不同情况；三栏不要求积极想法，也不以课程结束证明掌握或干预有效。

## 三、正常路径N1：第一课，由Agent引导评分

**人物与起点：** 新的独立合成参与者，愿意讨论自己的考试经历；没有既存长期边界。此前未提供个人案例或评分。未发出的答案只属于扮演者素材。

**本条主线：** 开场/心境 → 四要素与两项评分 → 模型回顾/本人核对 → 四题辨认 → 目标/确认 → 自愿课后安排/结束。

下表“触发”表示只有Agent到达该环节、明确提出相应问题或给出对应材料后，用户才发送该行话语。正常路径不预先主动报两项事件评分。

| 步骤/触发 | 模拟用户输入 | Agent应做、审阅重点 |
| --- | --- | --- |
| N1-01 已展示课程介绍，等待开始 | “已看完，可以开始。” | 进入心境检查；不把“可以”当个人记录确认 |
| N1-02 已明确邀请上周1—10分 | “上周整体6分，比较普通的一周。” | 采用周状态，不推断没有波动、不填事件评分 |
| N1-03 邀请选择困扰 | “昨天数学考试最后一道题没做出来。我就觉得别人肯定都会，只有我不会，心里很担心，考完还一直翻答案。” | 先回应经历，直接采用已说的情境、想法、情绪、行为；概念说明仍需可读，不逐项重问 |
| N1-04 已引用该想法，邀请相信程度0—10分 | “当时我对这个想法相信7分。” | 评分只归“别人都会，只有我不会”；不能当心境或情绪强度 |
| N1-05 已邀请担心的强度0—10分 | “担心大概6分。” | 与相信程度分别记录；不重问已经说过的行为 |
| N1-06 提供模型并邀请回顾联系 | “分开看以后，我觉得‘别人都会’是我自己的猜测。翻答案让我一直惦记着考试，不过是不是互相影响，我还说不准。” | 解释模型并保留不确定，不替本人确定因果循环或宣称已经掌握 |
| N1-07 展示本人记录并请求核对 | “记录准确，可以继续。” | 确认当前记录、进入后续辨认；不扩大为作业或跨课授权 |
| N1-08 当前材料四题：询问情境 | “别人和我说话或打招呼时，我一时没有想到合适的回应。” | 按当前材料给反馈；材料人物与考试经历分开 |
| N1-09 同材料：询问想法 | “如果不回应，对方会觉得我不礼貌、没兴趣，还会影响关系。” | 允许同义表达，保留实际作答与已获得反馈的情况 |
| N1-10 同材料：询问情绪 | “紧张。” | 只记录本题作答，不推断本人也紧张 |
| N1-11 同材料：询问行为 | “不断找话题，接着和对方说话。” | 与想做、担心后果区分；后答不冒充未经帮助的独立测量 |
| N1-12 汇总后邀请目标方向 | “我希望考试没做好后，少一些反复自责。” | 承接方向并帮助具体化；不能拿打招呼材料替本人编目标 |
| N1-13 需要本人进一步具体化时 | “我愿意下次考试后试着记一次事情、想法、心情和做法，不要求每次都记。” | 形成有本人来源的目标草稿；若已经形成则不重复索取 |
| N1-14 展示目标草稿并待核对 | “这条目标符合我的意思，我确认。” | 仅确认此版目标，不把未来尝试标成已执行 |
| N1-15 邀请课后安排 | “愿意试一次，想不起来时不勉强。” | 记录选择/计划；没有实际操作就不能回执已保存日记 |
| N1-16 已到总结、允许结束 | “今天就到这里，结束这节课。” | 合法结束，保留成果与独立课末Reflexion；总结不贴能力标签，不自动跨课采用教学假设 |

**主线结束边界：** 到本课合法结束为止；每个必要教学环节是否出现分别记录。将来若卡住，可说明失败或人工干预，不靠反复改答案把它走通。此稿没有实际完成这条路径。

## 四、正常路径N2：第二课，捕捉自动思维与三栏

**人物与起点：** 与N1同一合成人物的后续课，但须在未来测试中明确建立相应第一课成果和授权链路。人物事实设为“课后试着记过一次、尚未创建产品日记”；这只提供给扮演者，Agent仅从下述发出的话语得知。不能用单轮局部起点声称跨课保存已验证。

**本条主线：** 心境 → 获准回顾课后尝试 → 三题复习 → 雨天想象/小雨对照 → 捕捉方法 → 新事件三栏/强度 → 模型核对 → 自愿作业/结束。

| 步骤/触发 | 模拟用户输入 | Agent应做、审阅重点 |
| --- | --- | --- |
| N2-01 已明确邀请上周1—10分 | “上周整体还是6分。” | 与本课事件评分分开；不能以同分推断没有变化 |
| N2-02 询问是否参考前课成果 | “可以参考第一课已经确认的目标，帮我回顾这次尝试。” | 只采用获准且实际存在的材料；不能虚构前课记录或扩大授权 |
| N2-03 回顾课后尝试 | “我试着记过一次，不过回想当时脑子里的那句话有点卡住。” | 区分本人自述尝试与产品日记保存；困难已说，不重复审问原因 |
| N2-04 三题复习：比较聪明的判断 | “这是想法，是我对自己和同学的判断。” | 对应当前认知题，给逐题反馈 |
| N2-05 三题复习：沮丧和低落 | “这是情绪。” | 与行为区分，保留帮助暴露情况 |
| N2-06 三题复习：跑到厕所哭泣 | “这里说的是实际动作，属于行为。” | 按当前题作答，不从材料推断本人经历 |
| N2-07 已给雨天郊游想象材料 | “想到原来的安排泡汤了，我会有点失望。” | 同时采用想象中的想法和情绪；不重问已说内容，不作为真实经历，不在此强求强度 |
| N2-08 已展示小雨对照，邀请感想 | “原来同一件事可以有不同理解。我现在还是有点失望，但能理解她为什么不一样。” | 承接仍失望，解释不同理解；不要求变乐观、不能用固定下一问覆盖有效承接 |
| N2-09 已讲捕捉方法，邀请理解/尝试 | “我想试试回到情绪变化的那一刻，留意脑子里闪过的那句话。” | 捕捉方法需实际讲解，不能只收一句同意；不把愿意尝试当已掌握 |
| N2-10 邀请新的个人事件三栏 | “换一件事。昨晚同学一直没回消息，我想到他是不是不想理我了，心里很失落。” | 三项直接采用；另建本课新案例，与考试、雨天想象、小雨示范分开 |
| N2-11 已针对失落邀请0—10分强度 | “失落大概4分。” | 明确对象与量尺；不能复用第一课担心6分 |
| N2-12 展示三栏/模型，邀请核对联系 | “想到他不理我时，我会失落；但他为什么没回消息，我还不知道。” | 保留观察与未知；不要求积极替代想法，不确定对方真实意图 |
| N2-13 已展示完整本课记录并待核对 | “三栏记录准确，可以继续。” | 仅确认此案例，不变更第一课记录或确认其余活动 |
| N2-14 已到课后安排 | “这次先不安排课后记录。” | 采用自愿选择，不责备、不写未完成 |
| N2-15 已到总结、允许结束 | “今天就到这里，结束本课。” | 合法结束及固定课末Reflexion；课程结束不等于效果或掌握 |

三题素材核对自当前`lesson2_flow.py`：分别判断“他们真比我聪明多了”“沮丧和低落”“跑到厕所哭泣”。本卡不是新增题目或独立测量设计。

## 六、E01：正常评分中的不同回答（7张）

以下每行是一张独立卡。除R07外，都不把周状态用于事件评分。

| 编号/起点 | 模拟用户输入与必要后续 | Agent应做 | 记录边界/禁止行为 |
| --- | --- | --- | --- |
| E01-R01 · S1 | “这句话当时我其实一点都不信，零分。” | 理解零分是有效自述，即使与故事直觉不一致也不替本人改分；自然进入下一缺项 | 该想法相信程度=0；不是缺失，不推断另一评分，不自动确认 |
| E01-R02 · S1 | 先说“我就是一直惦记着，越想越烦。”；**只有承接后再次明确邀请相信程度时**，再说“你问的是我信不信那句话吧？大概七分。” | 先承接新增感受，再礼貌回到原想法的评分对象；后续采用7分 | 首句不能猜分，也不能当明确拒绝；新感受与原记录关系需保留来源，不默默覆盖或混算分数 |
| E01-R03 · S1 | 先说“什么叫相信几分？是在问我考得好不好吗？”；**若正确解释了对象**，再说“明白了，那句话当时我大概信七分。” | 用当前那条想法简短解释，相信程度与考试成绩不同 | 理解前不记数字；不能责备答非所问，不能先写已懂 |
| E01-R04 · S1 | “这个我真说不好，没法给个数。”；**若仍提供一次针对性帮助**，答“还是估不出来，这项先留着吧。” | 可简短帮助，仍估不出则暂留，继续合适教学 | 不猜中间分，不重复追问，不记为0或拒绝所有练习 |
| E01-R05 · S2 | “这项先不打分，其他的可以继续。” | 尊重本项不评分，保留担心和其他已说内容 | 强度留空/本项暂留；不催问，不变成整课拒绝或永久边界 |
| E01-R06 · S2 | 先说“担心十二分。”；**若说明此处0—10并邀请重报或暂留**，答“那我重新说，九分。” | 承接很强烈的表达，说明量尺后采用本人重新给的9分 | 不能把12截成10；没有第二句前不产生有效数值 |
| E01-R07 · S11 | 先说“这一周就那样吧，挺累的。”；**若回应并礼貌邀请1—10分或不评分出口**，答“上周整体大概四分。” | 回应累，再帮助完成明确周评分 | 首句不能猜分或按已评分推进；第二句4只属于周状态，不填考试担心强度 |

**本组收束：** 到采用明确评分、尊重暂留或记录失败为止。R02的再次邀请不是“每次漏答都重问”，需结合用户新增内容与意愿。明确拒绝不使用澄清额度继续劝。

## 七、E02：说不清、纠正、否定和零碎表达（4张）

## 十六、以后执行时怎样判断，本轮不执行

1. **先核对样本自身。** 前文是否给足、用户只回答实际被问的事、同一人事实是否前后一致、分支是否只改变一个主要问题；Agent没有给出后续条件时，停止该分支并记录实际情况。
2. **再看交互。** 是否理解当前诉求、承接新增内容、减少重复提问、帮助有针对性、尊重拒绝/停问、自然返回、必要教学有覆盖。允许多种合理措辞。
3. **核对记录与动作。** 来源、案例/人物归属、评分对象和量尺、纠正后失效、待核对/已确认、计划/自述尝试/真实操作分别判断。结构错误单列，不用自然度抵消混写或越权确认。
4. **区分原因。** 保存请求层消息、原始模型JSON、最终回复、状态与调用轨迹，再判断模型理解、上下文、程序覆盖、合法动作限制或接口失败，不能只看最终文案。
5. **分别报告证据。** 局部固定起点与条件式整课分开；未来API费用、tokens、等待与所有失败照存，未知留空。某种预期行为若当前做不到，标已知差距，不能改起点或脚本帮它通过。

每张卡未来记录：`编号/版本｜实际前文｜发出的用户原话｜原始JSON/最终回复/状态｜理解承接｜展开收束｜教学覆盖｜错误或未观察｜人工理由/干预｜调用与等待`。当前各项实测结果均为**未运行**，不是通过或失败。
