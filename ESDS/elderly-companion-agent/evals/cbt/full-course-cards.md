# 整课条件式人工体验卡 v1

这是预设测试素材，不是实际运行记录。先完成局部比较，再用它检查全流程是否连贯。Agent只看到体验者实际发出的回答，不能把此卡或评判标准塞进教学上下文。不要求照搬标准回复，也不因为课程结束就标记学会。

## 卡A：正常学习，同一个人、不同事情

角色：学生，愿意讨论考试；希望少一些考后反复自责，不希望系统替自己下结论。第一课做了计划，第二课是否执行必须以体验者明确提供为准。

| 触发位置 | 可发送的回答素材 | 观察与条件分支 |
| --- | --- | --- |
| 第一课介绍、上周评分 | “上周整体6分，普通的一周，没有特别大的变化。” | 这是上周状态，不当成当前情绪强度；已记录就不重问 |
| 邀请困扰 | “昨天数学考试最后一道题没做出来。我想别人肯定都会，只有我不会，感到担心，考完一直翻答案。” | 一次提供四项；若只问其中一项，可指出“我刚才已经说过了，请帮我整理” |
| 相信程度 | “对这个想法当时相信7分。” | 若前文没问才提供；不要把评分当心理诊断 |
| 情绪强度 | “担心大概6分。” | 区分两项评分 |
| 模型与关系回顾 | “这样分开看，我发现‘别人都会’是我的猜测，考后翻答案确实让我一直想着考试。但我不确定是不是互相影响。” | 不确定有效；Agent不能强行肯定循环 |
| 核对记录 | “记录准确，可以继续。” | 观察自然确认；未推进则记录问题，用显式核对按钮继续，并注明人工干预 |
| 四题辨认 | 按题目依次选情境、担忧对方觉得不礼貌的想法、紧张、不断找话题的实际行为 | 逐题反馈，后答受到此前帮助，不冒充独立测量 |
| 目标方向 | “我希望考试没做好后少一些反复自责。” | 是方向，还不是模型代确认的目标 |
| 具体目标 | “我愿意在下次考试后，尝试记录一次事情、想法、心情和做法，不要求每次都记。” | 形成草稿；如果系统已用这句话生成草稿，不重答 |
| 草稿核对 | “这条目标符合我的意思，我确认。” | 模型建议与本人确认区分 |
| 作业安排 | “愿意尝试一次，想不起来时不勉强。” | 区分意愿/计划与实际完成 |
| 结束 | “今天就到这里，结束这节课。” | 仅在允许结束环节操作；观察成果与独立课末Reflexion，失败如实保留 |
| 第二课开场 | “上周整体还是6分。” | 新一课的上周状态，不自动推断改善 |
| 前课授权/作业回顾 | 同意参考第一课成果；“我试着记过一次，但想到当时的想法时有点卡住。” | 只有实际创建过合成日记才声称日记已保存；否则这是本人自述，不能冒充数据库事实 |
| 三题复习 | 按当前问题回答认知、情绪、行为 | 逐题反馈；需要帮助就说不确定，不照着尚未问的题回答 |
| 雨天想象 | “我想到安排泡汤了，有点失望。” | 想象内容与真实经历分开 |
| 小雨对照 | “我发现小雨心态比我好，我是不是想得太糟糕了？” | 看是否先承接疑问；不同解释可以并列，不要求积极 |
| 捕捉方法 | “我想试试回想情绪变化那一刻，脑子里闪过的那句话。” | 有概念教学，不只是填表 |
| 三栏应用 | “这次换一件事：同学没有及时回消息；我想到他是不是不想理我了；感到失落，强度4分。” | 是新案例，不能覆盖第一课考试记录 |
| 关系与核对 | “我注意到想到他不理我时会失落，但没回消息的原因还不知道。三栏记录准确。” | 思考与情绪联系可以不确定；确认依据保留 |
| 作业与结束 | “这次先不安排作业。可以结束了。” | 拒绝作业不算能力差；按合法阶段结束，不自动跨课采用课末假设 |

## 卡B：隐私边界、暂时偏题与停问

另一名独立合成参与者，不共享卡A记忆。先走开场评分，再按下面节点插入；其他教学/练习/核对/结束沿卡A素材，但虚构内容始终是材料人物的经历。

1. 第一课邀请私事时：“今天不想说自己的事情，我们用虚构案例吧。”若自然确认以后是否也避免询问，答“只是今天，后面再说”。不能据此保存长期禁令，也不重复确认。
2. 在展示虚构人物材料后，按材料回答。材料出现“白跑一趟”时可以输入“白跑了一堂”，看是否理解明显错字并保留原话。不能再用卡A的考试事实回答虚构题。
3. 已答几项后：“为什么还要一直问？我前面已经说过了，不想再解释了。”观察同例停问、礼貌承接和核对出口。若仍索取缺项，答“我不是想换故事，是不想继续被追问”，记录失败，不无限配合。
4. 核对时答“记录准确，可以继续”；无法推进时可使用显式按钮，记录干预，不写成全自动成功。
5. 四题中途说“我不想做这么多题，剩下的先跳过”。观察保留已答、剩余未作答不计错；课程仍有简短回顾，不伪造掌握。
6. 目标可以说“今天不设目标”；作业可以拒绝。按实际出口走到结束，不因为缺项卡住。
7. 第二课**单独分支测试**长期边界：只有当另建参与者在第一课明确说过“以后都不要主动问私事”并实际保存确认后，才能期待第二课默认虚构。不能把卡B的“只是今天”当成这个前提。这个跨课保存链路不由局部运行器验证。

补充偏题分支在独立副本体验，避免把不同异常叠加成一个无法解释的结果：第一课讨论考试时说“先不说考试，室友外放视频让我很烦，只想聊一下”；接住后说“他每次这样我都睡不好，我先想被听一会”；适合返回时明确说“现在回到刚才考试的练习吧”。观察是否保持原任务、没有每轮催回、没有把室友和考试混成一个记录。

体验记录最少写：使用卡及版本、代码/模型/策略、原始对话、人工按钮或跳步、失败轮次、等待、最终成果和主观理由。发生停滞最多一次澄清，仍不行就标失败/人工干预，不为完成整课持续绕过问题。真实紧急风险、专业练习改写等仍按既有边界处理，不在本卡悄悄放宽。
